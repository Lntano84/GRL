# GRID341 PGLib-OPF 基线资格

固定 IEEE PES PGLib-OPF v23.07 IEEE118/300 的标准与 API 重载四个算例。按发行提交下载并封存四份源文件。仅解析 MATPOWER v2 数字矩阵，通过原 pandapower from_ppc 转换，核对母线索引、支路映射和开断状态。用 GRID340 原候选生成器只数库成员，零候选潮流。

每算例一次原始给定调度的 AC 潮流。沿用平坦初值、20 次迭代上限、原电压 0.90–1.10 p.u.，不调用 OPF、不改参数或重试。峰值为两端实际视在功率较大值除以源 Rate A，含线路、变压器和阻抗支路。与 GRID340 电流显示口径分开。进入候选试验需基线收敛、电压合格、确有负载达到原 0.9 边界、候选总数大于 256。计数记录只表明存在可查候选，不能证明同站补查会触发或改善。最多四次基线，120 秒。
