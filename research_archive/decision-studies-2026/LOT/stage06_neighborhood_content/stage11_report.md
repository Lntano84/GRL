# Stage 11：固定位置的匹配对照

## 唯一研究问题

> 在固定 Z 的数量、机器分布及原计划中的 0/1 构成都匹配时，固定远期 Z 是否仍然更有效？

**待证伪假设**：AB 的收益不仅来自减少名义上的自由二元变量数量；固定远期延续这一位置，连同它引起的约束传播，有额外价值。

## 裁决：**预先写定的探索性判据判为"不确定"**

| 判据 | 取值 | 通过 |
|---|---|---|
| AB 对匹配随机平均 ≥ 2% | **+1.70%** | **否** |
| 至少 6/8 实例为正 | **6/8** | 是 |
| 两个 ρ 组均为正 | rho0.75 **+1.50%**、rho1.10 **+1.90%** | 是 |
| 三个随机集合都给出 AB 优势 | 是（+1.41% / +2.14% / +1.56%） | 是 |

**⇒ 按预案最后一条：效果小（+1.70%，低于 2% 工程参考）、两个实例为负且种子方向相反 → 记为不确定，不启动学习，也不事后挑选有利的随机集合。**

**机制结论（本轮最有价值的产出）**：**固定远期 Z 的"位置"并不是 AB 收益的主要来源。** 把同样数量、同样机器分布、同样 0/1 构成的 792 个 Z 随机固定，就能拿到 AB 的绝大部分收益：

| 配置 | 释放数 | 平均 G（对 J_r） | presolve 后二元数 |
|---|---:|---:|---:|
| **AB** | 1296 | **+0.2272** | **831.50** |
| MR-Z-1 | 1296 | +0.2131 | 936.88 |
| MR-Z-2 | 1296 | +0.2058 | 932.06 |
| MR-Z-3 | 1296 | +0.2116 | 932.88 |
| ABC（完整 EMPTY） | 2088 | +0.0992 | 1682.75 |

AB 比匹配随机均值只好 **+1.70%**，而三者相比 ABC 都好 **+11% 上下**。

**并且（本轮修正后的新事实）**：在**匹配名义固定数量**之后，**AB 仍然产生了更小的预处理后模型**——96/96 个配对中 AB 的 presolve 后二元变量都更少，平均少 **102.44** 个。**因此不能说"更多变量消除已被否证"**；相反，名义匹配**不**带来预处理规模匹配。但这**也不能**证明那 +1.70% 就是这些变量消除造成的。

**对 AB 研究定位的修正**：Stage 10 确认的是**这条规则有效**；Stage 11 削弱了"必须固定全部远期 Z"的论据，但**没有识别出完整的因果机制，也没有证明位置效应不存在**。随机方法仍保留了约 65% 的 C，所有对照都围绕同一修复计划、同一类 Z 变量构造。

## 1. 匹配随机对照的精确定义（已按你的澄清修正）

记 `U = B ∪ C`（全部非结构固定的 Z 槽位，`Z_ij0`/`Z_ijT` 结构固定，永不参与），`U_h = {z ∈ U : (机器 j, S_r 值) = h}`，`q_h = |C ∩ U_h|`。

**每个层 h 从完整的 `U_h` 中无放回抽取 `q_h` 个固定，其余 Z 全部释放。** 因为 `C ∩ U_h ⊆ U_h`，恒有 `q_h ≤ |U_h|`，配额不可能供给不足——**C 不从候选池中删除**，随机集允许保留大量 C，也允许恰好抽回 C。

**我上一轮的判断错在哪里**：我曾把 C 从池中排除，于是池子只剩 B，配额必然不足，从而错误地得出"对照不存在"。正确的读法是：**"不碰短期 Y" ≠ "不碰 B"**——B 是**短期 Z**，而随机对照正是要打乱 B 与 C 之间"被固定/被释放"的身份。

**集合检查结果**（`stage11_matched_random.py`，纯离线、不求解）：

| 检查 | 结果 |
|---|---|
| 每个随机集的固定数量 | **792 / 792 / 792**（等于 \|C\|） |
| 每层配额与 AB 完全相同 | 通过（逐层断言） |
| 控制退化（只能固定 C）的状态 | **0/16** |
| 存在真正选择的层数 | 每状态 **6/6** 层（`0 < q_h < \|U_h\|`） |
| 固定集是否含结构固定槽位 | 否 |
| 与 AB 的重合率 | **0.646 / 0.651 / 0.646**（**未因重合率高而重抽**） |
| 三个集合互不相同 | 16/16 状态 |
| 二元规范化最大误差 | 7.1e-15 |

每个随机集平均固定 **~513 个 C 槽位**、**~279 个 B 槽位**，同时留下 ~279 个 C 槽位与 ~153 个 B 槽位自由——这正是它区别于 AB 的地方。

## 2. 主指标

```
G_n = mean_{d,s} ( (1/3) Σ_r J_{MR-r,n,d,s} − J_{AB,n,d,s} ) / max(1, |J_r,n,d|)
```

三个随机集在**每个 (故障, 种子) 对内部**先平均，再按名义实例汇总——**主对照取三者均值，绝不取事后最优者**。

| 项目 | 取值 |
|---|---|
| 名义实例数 | 8 |
| **平均** | **+0.0170** |
| 中位 | +0.0172 |
| min / max | −0.0023 / +0.0548 |
| **正 / 负 / 平** | **6 / 2 / 0** |
| ρ=0.75 | +0.0150（4/4 为正） |
| ρ=1.10 | +0.0190（**2/4 为正**） |
| **每种子的方向** | 6 同 / **2 相反** |

**逐实例**

| 实例 | G_n |
|---|---:|
| large_rho0.75_s2 | +0.0253 |
| large_rho0.75_s3 | +0.0169 |
| large_rho0.75_s4 | **+0.0004** |
| large_rho0.75_s5 | +0.0175 |
| large_rho1.10_s2 | **−0.0023** |
| large_rho1.10_s3 | +0.0243 |
| large_rho1.10_s4 | **−0.0008** |
| large_rho1.10_s5 | +0.0548 |

两个为负的实例（`rho1.10_s2`、`rho1.10_s4`）幅度都在 0.25% 以内，且**都是种子方向相反**的实例（另有 `rho0.75_s4`）。**这正是预案中"效果小、分组反向"的情形。**

**三个随机集之间的波动**：AB vs MR-Z-1 = +0.0141、vs MR-Z-2 = +0.0214、vs MR-Z-3 = +0.0156，**三者极差 0.0073**，方向一致。即使按"每次都挑对 AB 最有利的那个随机集"这一**不使用的 oracle** 计算，也只有 +0.0260——这说明随机集的选择本身影响有限，**AB 相对随机固定的优势确实存在但很小**。

**复测对照 AB vs ABC**：+0.1279（8/8 为正，rho0.75 +0.2091、rho1.10 +0.0468）。与 Stage 09B 的 +0.1292 一致。

## 3. 三项机制诊断

> **本节初版的两张表已被撤回。** 详见第 5 节 C17/C18：初版的"实际缩减"用的是**加载模型规模**与**未释放槽位数**（均非 presolve 后规模与剩余自由二元数），"松弛界"整张表的 80 次求解**全部没有发生**（`Not Set`、目标为默认 0、约 30 微秒），因此那张表在代数上等于 `1 − G`，不含任何松弛信息。以下是**用已有日志离线重算**与**重新完成的 80 个有效松弛**的结果。

### ① 真实 presolve：名义匹配**不**等于预处理规模匹配

从全部 **160 份 MIP 日志**中提取首次出现的 `Solving MIP model with:` 块（即 HiGHS 真正求解的**预处理后**模型），**无需重新求解**：

| 配置 | n | 行数 | 列数 | **二元变量数** |
|---|---:|---:|---:|---:|
| **AB** | 32 | 1796.00 | 2111.38 | **831.50** |
| MR-Z-1 | 32 | 2017.19 | 2214.88 | 936.88 |
| MR-Z-2 | 32 | 2005.19 | 2208.75 | 932.06 |
| MR-Z-3 | 32 | 2007.19 | 2209.38 | 932.88 |
| ABC | 32 | 4490.50 | 3226.62 | 1682.75 |

**96/96 个 AB—随机配对中，AB 的 presolve 后二元变量都更少，少 58–202 个，平均少 102.44 个。</strong>**

**结论**：**匹配名义固定数量不保证匹配实际搜索维度**，AB 在预处理后仍然一致更小。这**削弱**了"位置完全无关"的说法（初版正是因为算错而宣称该解释已被否证）；但**它本身不证明**那 +1.70% 来自这些变量消除——presolve 更小与搜索更好之间的因果方向仍需另行检验。

### ② 有效 LP 松弛：80/80 有效且**全部证最优**

构造方式（已按你的要求收紧）：先按**正常 MIP 路径**装配该配置（含固定条件与稳定性行），再**只把整数类型改为连续**，成本/矩阵/行列边界完全一致；释放变量保持 [0,1] 真正自由；单线程在首次求解前统一设置；记录返回码、模型状态、解有效性与完整日志；`Error`/`Not Set`/无有效解一律记为**缺失**，绝不把默认值入表。

| 配置 | 平均 L | min L | 证最优 | 平均耗时 |
|---|---:|---:|---:|---:|
| AB | 4174.63 | 1453.95 | **16/16** | 0.042 s |
| ABC | **3828.03** | **1400.10** | **16/16** | 0.142 s |
| MR-Z-1 | 4244.10 | 1575.77 | **16/16** | 0.042 s |
| MR-Z-2 | 4324.22 | 1614.62 | **16/16** | 0.038 s |
| MR-Z-3 | 4261.12 | 1616.46 | **16/16** | 0.040 s |

**80/80 有效、0 缺失**（合计 6.3 秒）。逐状态 80 个数值见 `stage11b_analysis.json`。

### ③ 包含关系检查：全部成立

- **`L_ABC ≤ L_AB`：16/16 成立**；**`L_ABC ≤ L_MR`：48/48 成立**（三个随机集各 16）。
- **`L_m ≤ J_m,有效方案`：160/160 成立**（80 个松弛 × 2 个种子）。松弛界确实界住了交付的可行解。
- **AB 与 MR 互不嵌套**，其界**没有**固定顺序：例如 `rho1.10_s3|D2` 上 AB 6243.56 高于三个 MR（6375/6372/6398，即 AB 的界更低），而 `rho0.75_s2|D1` 上 AB 1718.45 低于 MR（2027/2074/2005，即 AB 的界更高）。与预期一致。
- ABC 的松弛界系统性最低（嵌套关系的外层），与 `ABC ⊇ AB, MR` 一致。

### ④ 迁移检查重新分类

96 次检查中 **9 次允许 AB 方案**，重新分类后：**MR 更差 5 次、MR 更好 4 次、相等 0 次。**

- 只有 **5 个"MR 更差"**支持"该随机配置本可使用这份 AB 好解、却未在预算内达到同等质量"（`rho0.75_s4|D1` 三个随机集 + `rho1.10_s4|D1` 的 MR-Z-1/-2）。
- **4 个"MR 更好"**（`rho1.10_s4|D1` 的 MR-Z-3，以及该状态 s1 的三个随机集）方向相反，**不能**计入上述判断。
- 其余 87 次迁移失败只记录违反的固定条件（Z 违反 1–10 个，短期 Y 违反恒为 0），**不说明随机配置的最优值更差**。

## 4. 结论与下一步

**目前可以写**：

> 在这批开发实例中，匹配随机固定 Z 也获得了较大的限时收益。AB 相对随机固定的额外收益为 **1.70%**，未达到预设工程判据；同时，**AB 的实际 presolve 后模型始终更小**（96/96 配对，平均少 102.44 个二元变量）。

**暂时不能写**：

> ~~效力已被证明来自通用降维，与远期位置无关。~~

**本轮削弱了"必须固定全部远期 Z"的论据，没有识别出完整的因果机制，也没有证明位置效应不存在。** 随机方法仍保留约 65% 的 C，且所有对照都围绕同一修复计划、同一类 Z 变量构造。

按预案逐条对照：

| 预案 | 是否成立 | 证据 |
|---|---|---|
| 平均 ≥2%、≥6/8 为正、两组均正 → 支持继续研究固定位置与约束传播机制 | **不成立**（均值仅 +1.70%） | 6/8 为正、两组均正，但均值未过线 |
| 随机固定获得相近改善、AB 无稳定额外收益 → 优先解释一般固定优化 | **成立**（但解释方向已修正） | MR +20.6%~+21.3% vs AB +22.7%，而 ABC 仅 +9.9% |
| 随机固定稳定更好 → 修正 AB 定位 | 不成立 | AB 仍在三个随机集之上，只是幅度小 |
| 效果小、分组反向或随机集间波动大 → 记为不确定，不启动学习，不事后挑集合 | **成立** | 均值 +1.70%<2%、2 实例为负且种子方向相反 |

**下一步（本轮不做）**

1. **已确立的有效测量**：真实 presolve 规模（AB 一致更小）与 80 个**证最优**的松弛界。
2. **两个待分辨的方向**（需先用本轮测量判断该针对哪一个）：
   - **搜索规模**：AB 的 presolve 后模型一致更小（少 58–202 个二元），而 AB 与 MR 的**松弛界并无固定顺序**。若收益来自规模，应能找到"规模差 ↔ 收益差"的关系；若无，则应转向
   - **受限问题保留了哪些高质量解**：迁移检查中 9 例允许 AB 方案，其中 5 例 MR 更差、4 例 MR 更好。这提示限制集**保留了什么**比规模本身更值得看。
3. **不要**因为 AB 在三个随机集之上就坚持"位置有价值"：+1.70% 在预案线以下，2 个实例为负。
4. **研究方向继续保留，GRL 仍不启动。**

## 6. 边界

- **不是"时间位置本身"的纯因果实验**：不同位置与已固定 Y 的连接不同，本轮测的正是这种结构差异是否值得继续解释——结论是**尚不足以把它当作核心贡献**。
- **8 个开发实例、16 个状态、2 个种子**；这是**机制开发实验**，Stage 10 仍是独立确认记录，**本轮不构成第二次泛化确认**。
- **匹配的是名义数量、机器分布与 0/1 构成**；①已证明这三项匹配**不**带来 presolve 规模匹配（AB 仍一致更小），因此"位置完全无关"并未被证明。
- **presolve 规模更小与限时收益更好之间的因果方向尚未检验**；②的松弛界在 AB 与 MR 之间**没有固定顺序**，这既不能确认也不能否定"规模解释"。
- **限时结果**：全部 0/32 证最优（MIP），故"AB 优于随机"是 **20 秒预算下的搜索效果差异**，不是数学优势。
- `G` 是相对 `|J_r|` 的相对差，**不是最优性间隙**。
- 2% 仅为工程参考。
- 未生成新实例、未改名义计划/修复器/κ/模型/求解器配置、未细分 `Z_τ`、未调参、未训练模型；**Stage 11b 未重跑任何 MIP**（松弛诊断合计 6.3 秒，远低于 400 秒上限）。
