# FRAME 中文摘要｜用户确认稿 V3

在线电网拓扑控制通过仿真比较候选动作，大量逐次评估会增加控制器的计算开销。不同运行状态下需要评估的动作数量不同，固定的查询次数难以兼顾计算效率和动作选择效果。针对这一问题，本文提出反馈驱动的拓扑搜索框架FRAME，先评估候选序列中的一批动作，再根据仿真结果决定是否继续搜索，必要时补查当前最佳动作所属变电站的其余候选。FRAME复用已获得的仿真结果，保留最佳已评估动作，可直接接入现有控制器，无需额外训练搜索控制策略。在一个公开电网的6个生成时序场景上，相对完整候选搜索，FRAME的查询量和完整控制时间宏平均分别减少65.10%和14.98%。与基于ICAPS 2022元推理方法构建的电网适配对照相比，FRAME的完整控制时间在五个训练种子比较中平均减少2.23%。
