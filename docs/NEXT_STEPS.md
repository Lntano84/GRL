# GRID326 固定 DC 混排

GRID326 固定首 64 原序、另 64 DC 候选。开发 62 调用相对原序 19 胜、40 平、3 负，FULL 最优命中原序 / 纯 DC / 混排为 27 / 42 / 43。救回三月第 110 步，第 539 步仍丢失可接纳动作，原训练分区另有一次接纳退化。固定混排未过保留条件。复用原 DC 排序，零新增求解、拟合、打分或仿真。

手动推进。保留 208 和 261。首批零漏失仍作为等预算覆盖指标。补充核对的两例在原回退后都找回同一最终动作，全局各多查 64 个候选。后续不按已暴露反例调整配额。如进一步验证混排，先固定原回退并比较回退后的动作、全量查询和耗时，再决定同排序同 0.9 保护下的 208、261 和原 FRAME 的闭环范围。GRID324 停查头仍未获训练资格。
