# e-Energy 匿名审阅源稿

已从核对过 SHA-256 的英文稿生成 ACM `sigconf,review,anonymous` LaTeX 源稿。局部替换两批内部项目编号，在评估节加入已归档的后端、PyTorch intra-op 和近期 OSQP 设置。稿件主线、配对表 12 行、2035 同站补查、2039 三月反例和九月共同短周均保留。生成器核对 Markdown 源文件哈希，检查表行、引用与可识别字串。内部版 Markdown 和原 CSV 保留。

匿名稿与复现数据附件放在 D 盘协作区，仅供审阅。生成方法是在本目录运行 `python -B -X utf8 build_anonymous_source.py <新的本地目录>`。审阅源稿使用通用文件名，保留本文引用的外部资料链接。定稿前同时检查 PDF 元数据、项目可识别链接和公开数据指纹。

格式采用 2026-10-20 保存的 [征稿核对](../eenergy2027_reading_20261020/2027官方征稿要求_中文核对.md)。本次直接访问 [e-Energy 2027 官方 CFP](https://energy.acm.org/conferences/eenergy/2027/pages/cfp.php) 返回 403，冬季投稿页面可访问但无可读取的条款。正式提交前以官网当前要求确认格式、页数与时间。

Windows 与现有 Ubuntu 环境均未找到可用的 LaTeX 编译器。当前交付为 `manuscript.tex`，PDF 的编译、视觉和页数检查待完成。表格附件已通过独立重建。未向投稿系统提交任何材料。
