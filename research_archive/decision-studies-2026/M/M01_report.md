# M01 —— 三轮随机匹配中，完整策略相对「一步前瞻＋贪心续接」还剩多少收益

## 一页结论

**主指标 `d_robust`（即使把 R 的首轮并列往最有利方向打破后仍留下的损失）最大值只有 0.03906 个期望匹配顶点，远低于门槛（6 顶点 0.06、8 顶点 0.08）。**
32 个配置全部完成，**没有一个达到门槛**。

**裁决：B_stop。**
按预先固定的判读表：**停止在这批小图分布上挖掘「三轮前瞻修正」**。
这不否定更大图上的任何结论，也不构成对学习方法的否定。

**最重要的定量结论：前瞻已经把贪心几乎全部缺口补掉了。**
贪心缺口 `d_G` 在 25/32 个配置上为正，均值 0.1011、最大 0.2500；
而 `d_robust` 的均值只有 0.00151，最大 0.01536。
在 `d_G > 0` 的配置上，`d_robust / d_G` 的均值为 0.0525（最大 1.0000）。

> 按任务预先写下的判读：**如果 `d_G` 很大而 `d_robust` 很小，正确结论是「前瞻已经解决主要
> 问题，贪心反例不足以支持学习」。本轮正是这个情形。**

## 1. 冻结的任务语义

| 项 | 值 |
|---|---|
| 模型 | 无向简单图；每条边的成功状态独立且**全程保持不变** |
| 每轮 | 选择一个匹配；**允许非极大匹配和空匹配** |
| 成功边 | 贡献 **2 个匹配顶点**，两端点及其关联边退出 |
| 失败边 | **永久删除**，端点保留 |
| 观察 | 只观察本轮选择的边；未选边的真实状态永不读取 |
| 轮数 | **3 轮**；`h` 含当前轮，`V_0 = 0` |
| 目标 | 期望匹配顶点数 |
| `ε` | `1e-10 × max(1, n)` |
| 并列 | 字典序最小的排序边元组 |
| 蒙特卡洛 | **未使用**；全部为精确枚举 + 记忆化 |

三个方法的定义严格分开（`V_h^G` 用完整前瞻评估贪心动作规则；`V_h^R` 是**实际执行** R
规则的价值，不是 `max_M Q̃`；`V_h^*` 是完整有限轮次最优）。
R 在每一轮都重新求解，续接估计固定为完整贪心策略 `V^G`。

## 4. 独立复核（四个实例，全部通过）

对 (n,m) = (6,6) 且 s = 0,1 的两种概率配置共四例，**独立枚举全部 2^6 = 64 个持久边状态**，
在每例中执行保存下来的 G、R、OPT 策略。该路径**没有调用递归求值函数来生成收益**：

> **这一环查出并修掉了三处我自己的实现错误**，都发生在**独立复核脚本**里，
> 不在求解器里：(1) 动作表把贪心的近视分数当成 `V_G(·,h)` 返回，只在 `h=1` 正确；
> (2) 动作表把 R 的续接写成 R 自己，而定义要求续接是 G；
> (3) 模拟循环在遇到空匹配时 `break`，把空匹配当成了终止而不是「这一轮放弃」。
> 第 (3) 条尤其值得记录：空匹配是合法动作，它**消耗一轮但进程继续**。求解器本身没有这些问题，
> 并有下表所列的额外不变量检查。

### 4.1 顶点重标号不变量检查

任务语义把顶点视为无标号，因此 `V_3^*` 必须在重标号下**严格不变**。
把每个配置的顶点按 `v → (v+1) mod n` 与 `v → (v+2) mod n` 重标号（概率随边一起搬运，
不从排序位置重新赋值），重算全部量：

- `V_3^*`：32 个配置 × 2 次旋转，**最坏绝对偏差 8.882e-16，零失败**。
- `V_3^R`：跨标号最坏偏差 3.906e-02，**非零**。

后者不是错误，而是冻结设定的一条真实性质，必须报告：**贪心规则的并列由顶点标号的字典序决定**，
所以换标号可能改变贪心的选择；R 的续接估计正是 `V^G`，因此 `V_3^R` 与 `d_robust` 也带标号依赖。
本轮只有 2/32 个配置的 `d_robust` 在重标号下发生变化。

**因此本报告对每个配置同时给出原始标号的 `d_robust` 与三种标号下的最大值，判决采用最大值**（即对 R 最不利、最容易达到门槛的口径）。

## 7. 并列保护：`d_robust` 的含义与边界

`A_R` 记录三轮初始状态下**全部**达到最大前瞻分数（误差 ≤ ε）的动作，
`d_robust = V_3^* − max_{M∈A_R} Q_3^*(G, M)`：即使把 R 的首轮并列往最有利方向打破，
仍然留下的损失。
`|A_R|` 在每个配置上的取值见 `M01_results.csv` 的 `n_A_R` 列。

**必须保留的边界：**

1. `d_robust` 使用了 OPT 信息，**只是诊断量，不是可部署策略**。
2. 它**没有**排除贪心续接**内部**破并列的影响：R 的续接 `V^G` 在每个子状态都由字典序破并列，
   本轮没有对续接内部也做同样的最有利化。
3. 冻结的字典序规则在并列时**倾向选择空匹配**（空元组字典序最小），
   这系统性地压低了贪心（进而压低 `d_G` 的真实上限）。因此 `d_G` 的数值应读作
   「在冻结破并列规则下的贪心缺口」，而不是贪心规则的最坏情形。
   这一点对结论方向是保守的：真实贪心缺口只会更大，而 `d_robust` 依然远低于门槛。
4. 贪心规则的破并列是标号依赖的，所以 `d_G`、`d_R`、`d_robust` 都带标号依赖；
   判决已采用三种标号下的 `d_robust` 最大值。

## 8. 限制

1. **只有小图。** n ∈ {6, 8}、m ∈ {6, 8, 10, 12}。更大图上完全可能不同。
2. **只有合成图。** 是机制筛查，不能据此估计真实肾交换中的发生率。
3. **只有 3 轮。** 更长的轮次可能改变前瞻与最优的关系。
4. **R 是明确定义、动作完整枚举的前瞻对照**，不是作者的 greedy-k，
   也**不宣称已覆盖全部强方法**。
5. **续接估计固定为贪心**；其他续接估计（例如价值迭代、rollout）不在本轮范围内。
6. **未训练任何模型**，本轮不涉及学习。
7. **求解器没有与第三方库对拍**（环境无 networkx/numpy/scipy）；
   它经过四项解析校验、路径实例、64 世界全域枚举、以及 `V_3^*` 的顶点重标号不变量检查。
