# HANDOFF — Stage 18（无故障时名义计划是否也能被同一个 RINS 明显改善）

目录：`08_LOT_REOPT/stage06_neighborhood_content/`

## 问题与回答

> **在不发生故障、仍限制短期计划改动的情况下，RINS-LP-ONE 能否用 20 秒明显改善冻结的名义计划？**

**回答：能，而且幅度很大。命中预先固定的第 1 条。**

| 量（8 个名义实例，种子 1，20 秒） | 结果 |
|---|---|
| `G_total` 均值 / 中位数 | **+29.77%** / +28.49% |
| 范围 | **+1.65% ~ +58.43%** |
| 严格改善（>0） | **8/8** |
| ≥2% | **7/8** |
| rho0.75 / rho1.10 | **+34.70%**（4/4 正）/ **+24.85%**（4/4 正） |
| `G_continuous` | **+0.000000**（max \|·\| = 9.4e−16） |
| `G_binary` | **+29.77%** |
| 恒等式 `G_total = G_cont + G_bin` | **误差 0.00e+00** |
| 实际短期 Y 改动 | **1 或 4 位**（κ=4，全部合规） |

**⇒ 现有名义计划存在便宜、可重复利用的改进余地。下一步应先建立更强的名义计划版本，再检验故障后的方法表现；不能继续仅凭当前起点推导故障专属算法贡献。** 改善**几乎全部来自二元部分**（`G_continuous` = 0，即同二元结构下连续抛光已做不动）。

## 冻结执行

8 个 large 名义实例（seeds 2–5、两 ρ）；**原始无故障**容量与需求；参考计划 = `stage06_nominal.json` 的 \(S_N\)（**未重求、未覆盖**，与 `stage06_states.json` 的 `nominal_objective` 逐值一致）；**修复器不调用**；\(\tau=6,\kappa=4\) **相对 \(S_N\)**；**仅 RINS-LP-ONE**；种子 **1**；每实例 **20 秒**端到端；共 **8 次**，wall **160.8 s**，max overrun **0.078 s**。

流程完全复用现有方法：固定 \(S_N\) 全部二元求 \(S_{N,LP}\) → 求**无故障 FULL** 的 LP 松弛（保留相对 \(S_N\) 的 κ 行）→ 原 \(10^{-6}\) 一致性规则固定 → 提交 \(S_{N,LP}\) 求邻域 → 交付 \(\{S_N,S_{N,LP},S_{solver}\}\) 中最优有效者。**未使用任何故障后方案**作为起点或候选。fallback 0/8；两个 LP 均 `Optimal`。

邻域结构：固定 1822–2048、剩余自由 472–698；按组固定 A≈543 / B≈366 / C≈551 / short_Y≈389。

## 与记录 gap 的关系（谨慎）

8 个名义计划的**记录 gap 为 29.2%–73.8%**（均值 51.7%）。这些是**求解器自报的限时 gap**，**不能**证明计划差（gap 大也可能只是下界弱）。本轮给出的是**实测**：无故障、κ=4、20 秒下同一个 RINS 确实改善了约 **29.8%**（对 \(J_N\) 归一化）。两者不必一致，本轮不据此推断"离最优多远"。

## ⚠️ 边界

- **不能**认证名义计划接近最优（反向也不成立：本轮发现的是"有改进余地"，不是"离最优多远"）。
- **不能**拿本轮结果去减 Stage 17 的故障改善百分比：**参考计划、归一化分母、可行域都不同**（本轮 \(D_N=\max(1,|J_N|)\) vs Stage 17 \(D=\max(1,|J_r|)\)；参考解 \(S_N\) vs \(S_r\)），**差值不能当作"故障专属收益"**（已写入 `stage18_runs.json` 的 `meta.warning`）。
- 本轮是**单种子、单算法、20 秒的探针**：说明"存在改进余地"，**不构成对名义计划质量的完整刻画**。
- **不撤销 Stage 16–17 的方法比较**：那些比较在同一批状态、同一参考解 \(S_r\)、同一 κ 锚点下完成，仍然有效。

## 论文定位（本轮同步收紧）

用户核查一手来源后确认：**Lerouge 等（2026）**已直接研究"机器故障后，用原计划与扰动信息预测应释放的二元变量"；**IJCAI 2025 Balans** 已研究在线选择不同邻域算子。⇒ **"故障 + 学习释放变量"本身**、**"学习选择成熟邻域"本身**，**都不足以构成新意**。

| 项 | 状态 |
|---|---|
| 可信的工程底座 | **已有** |
| 有竞争力的非学习基线 | **已有**（RINS-LP-ONE，两种子下 8/8 稳定优于 AB） |
| **新的算法贡献** | **尚未建立** |
| **学习可利用的缺口** | **尚未证实** |

## 下一步建议

1. **先建立更强的名义计划版本**：把同一个 RINS-LP-ONE 探针直接用于**生成**名义计划（同样 20 秒、同样 κ 锚点、多种子取最好），得到 \(S_N^{*}\)，再把整条故障重优化实验线**在 \(S_N^{*}\) 上重做**。
2. **重做后的关键问题改变**：不再是"AB 是否优于 FULL"，而是**"在已经较强的起点上，故障后是否仍有非故障优化拿不到的、可被学习利用的缺口"**。这才是可能的新意所在。
3. **不建议**现在启动 GRL——**学习可利用的缺口尚未证实**。
4. **不建议**继续围绕 AB 扩展实验，也**不建议**再堆算法名称去验证"通用规则普遍支配固定规则"：那不是有限实验能证明、也不是我们需要证明的命题。
