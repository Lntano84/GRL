# GRID344 PEGASE1354 公开原始点资格结果

按已发布协议，对 MATPOWER 8.1 的公开虚构 PEGASE1354 原始点只运行一次 CPU Newton–Raphson AC。保留原运行设定、支路额定、50 Hz、平坦初值和原 0.90–1.10 p.u. 电压窗口。核对全部 1,991 条支路两端及投运状态。1,432 条设热限，559 条 Rate A=0 按原定义未设限，均保留在网络中。静态枚举 288 个站的 9,118 个候选位置。

热应力接近所需区间，但三处电压超限导致该原始点未过预注册资格。0 候选 AC、0 OPF、0 故障模拟、0 训练。保留已验证数据和停止判定，关闭这个公开点，不改电压或调度，也不选其他时点补考。该试验只给出基线资格结果，整套 FRAME 的前缀筛查、分批核查和同站补查在此均未进入运行对照。

现有跨平台材料支持接口移植，尚未形成运行性能可迁移的证据。GRID340 的 118 轻载是同一输出下的逻辑查询节省，GRID342 的 PGLib 重载则无合格候选，二者都保留。若后续有独立且能复现的拥塞运行点，应分别检验整套 FRAME 的质量和查询，以及同等预算下同站补查的增量。原 Grid2Op 261 与论文主表继续按既定计划。
