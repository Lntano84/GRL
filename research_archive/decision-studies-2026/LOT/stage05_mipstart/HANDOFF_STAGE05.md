## 3. 关键接口事实（避免重复踩坑）

1. `Highs` **没有** `getLog()`。采用证据用 `log_file` 选项 + 读回文件；日志文件必须**每次
   用 uuid 命名**（`id(h)` 会因 GC 复用地址而重名，曾导致冷启动读到热启动的日志）。
2. 采用证据的确定字符串：
   `MIP start solution is feasible, objective value is <v>`。
3. `scipy.optimize.milp` **无** MIP start 参数；能热启动的是 `highspy.setSolution`。
4. 短时限下两个求解器会停在**不同的 incumbent**，因此不能据此判断模型传输是否有误；
   传输正确性由 10 项数组逐项比较确认。
