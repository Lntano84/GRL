# N02 —— 保留局部不可辨识条件的定向反转检验

## 结论

**没有找到真实偏好反转。** 定向筛选后冻结的 8 个比较，在 8192 个全新世界上
确认反转 **0/8**，点估计反转 **0/8**。

**并且这批区间已经把 1 个激活节点的反转幅度排除掉了：8/8 个比较的最坏允许反转幅度都 < 1**
（最大的一个只有 0.1298）。

**裁决：D_stop。**
按预先固定的判读表，**在当前图和传播设置下停止继续定向挖掘**。
本轮不训练、不扩图、不调传播概率、不追加世界数。

这**不是**说两年局部代理没有表达限制——手工图已经证明它有；
也不是说这个限制不可能影响选种——本轮没有测量实用损失。
它只是说：**在图结构筛选把比较推到三跳交互最强的位置之后，
ca-GrQc 与当前传播参数下仍然没有出现值得追踪的反转幅度。**

---

## 1. 与 N01 相同、本轮唯一改变的东西

沿用的部分：同一条 ca-GrQc（同哈希、同节点映射）、双向独立 IC、
`p_uv = 1/deg(v)`、最多 100 轮、`k = 10`、背景 8 个节点、
每个世界四集合共享同一份 live-edge 状态、`R_h` 含源节点且按实际消息方向。

**保留原条件** `(R2(a)∪R2(b)) ∩ (R2(c)∪R2(d)) = ∅`，**不采用** N01-S 的放宽方式。
因此局部不可辨识条件仍然成立：没有任何输出节点的两层感受野能同时包含两侧候选，
两层逐节点求和代理必然给出 `δ̂_c = δ̂_d`。

唯一改变的是**比较的生成方式**：用图结构先挑出「两跳分离、三跳可能重叠」的四元组。

### 2.1 关于 Q_3 的两点必须披露的观察

我按规格使用了**原始 Q_3**，但先量化了它筛选的是什么（`N02_q3_diagnostic.json`）：

| 观察 | 数值 |
|---|---|
| 通过原条件的四元组中 Q_3 > 0 的比例 | 48,565/57,277 = 84.79% |
| 正值池的 Q_3 分布 | 最小 1，中位 4，p90 20，最大 164 |
| 入选 64 个的 Q_3 下界所处百分位 | **99.87%** |
| 入选四元组涉及的节点数 | 236（LCC 有 4158 个） |
| 原始 Q_3 前 64 与归一化 Q_3 前 64 的重叠 | **0/64** |

**含义：** Q_3 是三个交集大小的原始计数之和，因此主要度量「四个候选都落在稠密区」，
而不只是「两侧在三跳上真正交互」。84.79% 的合法四元组 Q_3 > 0，
所以原始 Q_3 实际上是按**三跳区域大小**排序，选出的 64 个集中在少数核心节点附近
（236 个不同节点、平均度数 7.55 对池内 6.46）；
若改用按分母归一化的 Q_3，前 64 名与本轮选出的 64 个**完全不重叠**。

这是**筛选分数的性质**，不是本轮结果的解释，也不改变任何判决：
我按规格执行了原始 Q_3，没有替换分数、没有重抽。

## 3. 开发批与冻结

- 世界种子 `2,000,000 … 2,000,255`，共 **256** 个新世界；
- 比较数 **128**（64 个四元组 × 2 种背景）；
- 世界×比较评估 32,768 次；
- 开发批分位点：普通 1.969311，调整后 3.780045（族大小 2N = 256）。

有符号反转幅度 `r_dev = max{ min(−δ_c, δ_d), min(δ_c, −δ_d) }`：
正值表示开发批点估计已反转，负值表示尚未反转。

| 统计 | 值 |
|---|---:|
| 最小 | -14.266 |
| 中位 | -3.488 |
| 最大 | -0.047 |
| `r_dev > 0` 的比较数 | **0/128** |

**开发批没有任何一个比较的点估计反转**，最接近的一个也只有 -0.047。按规格，仍照规则选每个背景的前 4 个（不换分数、不重抽）。

> **特权诊断披露。** 确认对象是用真实模拟结果筛出来的，因此**不是可部署策略**，
> 筛选后的反转比例**不能**估计自然发生率。

## 4. 独立确认

- 世界种子 `3,000,000 … 3,008,191`，共 **8192** 个全新世界，
  与开发批及所有旧实验范围不重叠；
- 8 个比较 × 8192 世界 = **65,536** 次评估；
  没有任何比较根据中途结果提前结束；
- 本轮合计 **98,304** 次「世界×比较」评估
  （开发批 32,768 + 确认批 65,536），与预期的约 98,304 量级一致；
- 16 个分差区间的分位点水平 `1 − 0.05/(4×8) = 0.99843750`，
  **由程序按闭式 t CDF 计算**：调整后 `t = 2.956044962`（df = 8191）；
- 区间仍为**近似 Monte Carlo 同时区间**，**不是严格有限样本证书**。

### 4.2 预先固定的判读

| 档位 | 条件 | 本轮 |
|---|---|---|
| A 支持继续 | ≥2 个**四节点集合互不重叠**的比较确认反转且各自 `m_L ≥ 1` | 否（0 个反转） |
| B 仅存在性 | 确认反转但只有单例或幅度不足 | 否（无反转） |
| C 未确定 | 未确认反转且区间仍宽 | 见下 |
| D 停止 | 未确认反转，且所选比较都被区间排除达到 1 节点的反转幅度 | **是** |

**两个读法都记录，以免用口径选择来规避结论：**

- **字面读法 → C_undetermined。** no m_U is defined under the pre-registered formula, because that formula requires the point estimates to have opposite signs and none do。
- **能力读法 → D_stop。** 8/8 个比较的调整区间已经无法容纳任何 ≥1 个激活节点的反转
（最大者仅 0.1298）。
  其中 7 个是「两区间同侧排除零」，第 8 个（比较ID 83）区间跨零，
  但其最坏允许反转幅度只有 0.1298。

**本轮的结论采用能力读法：D 档，停止在当前图和传播设置下继续定向挖掘。**
理由是预先选定的门槛（1 个激活节点）本就是一个**投入筛查门槛**，
而“区间跨零”与“区间排除该门槛”是两件不同的事；后者已经成立。

**1 个节点**是本轮预先选定的投入筛查门槛，不是论文通用标准，
也不等于完整 IM 的实用损失。两个比较即使成功也来自同一张图，不构成跨图泛化证据。

## 5. 本轮没有回答的问题

1. **没有测量实用损失。** 没有任何完整选种算法被运行，`m_L`、`m_U` 都不是后悔值。
2. **没有证明反转罕见。** 只在 8 个定向挑选的比较上做了确认；
   筛选方式决定了这里不能估计任何自然发生率。
3. **没有跨图、跨协议证据。** 只有 ca-GrQc、只有 IC 与 `p = 1/deg`、只有 `k = 10`。
4. **官方前向仍未实测。** `SpreadPredictor` 使用两层 `SAGEConv`、搜索时对逐节点输出求和，
   这支持局部依赖论证的适用性，但本机无 torch、无网络，官方前向单列为未完成。
5. **Q_3 筛选的定位。** 它是结构筛查，不是收益估计；它偏向了稠密核心区（§2.1）。

## 7. 与 N01 的关系

N01 在 40 个均匀抽取的比较上没观察到反转，但正如其修订版承认的，
那个设计**没有保证抽到接近决策边界的比较**。
N02 正是按这个缺口设计的：先把比较推到三跳交互最强的位置，再独立确认。
结果仍然是没有反转，且幅度被排除在投入门槛之下。

因此，与“靠继续换筛选分数把它拖成无限寻找反例的工程”相反，
本轮**按预先固定的规则收口**：
在当前图与传播设置下，这种模型限制**没有表现出值得追踪的选种决策后果**。
