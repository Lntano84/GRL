# HANDOFF — Stage 09B（哪个变量组值得释放）

目录：`08_LOT_REOPT/stage06_neighborhood_content/`

## 唯一问题

> 从连续最优的共同起点出发，只允许改变哪些二元变量组，能够在 20 秒内获得额外收益，并超过完整 EMPTY？

## 结论：释放 **A（远期 Y）+ B（短期 Z）**，保持 **C（远期 Z）固定**

`AB` 在 **8/8 个名义实例**上优于完整 EMPTY（ABC），平均 **+12.92%**；**31/32** 个 (状态,种子) 配对严格更优；两个求解器种子方向 **8/8 一致**；相对 `A` 平均 **+2.49%**、7/8 实例为正。这是一个**非学习的算法基线**，不是学习器。**仍是开发集证据，尚未独立确认**（见 Stage 10）。

| 配置 | 释放数 | `G_extra`（超 LP） | `G_restrict`（对 ABC） | 胜 ABC |
|---|---:|---:|---:|---:|
| **AB** | 1296 | **+0.1739** | **+0.1292** | **8/8** |
| A | 864 | +0.1490 | +0.1043 | 7/8 |
| BC | 1224 | +0.0611 | +0.0164 | 4/8 |
| ABC | 2088 | +0.0447 | 0（参照） | — |
| B | 432 | +0.0409 | −0.0038 | 4/8 |
| AC | 1656 | +0.0376 | −0.0071 | 1/8 |
| C | 792 | +0.0196 | −0.0251 | 4/8 |

分组定义：`A = {Y_ijt : t > τ}`、`B = {Z_ijt : 1 ≤ t ≤ τ}`、`C = {Z_ijt : τ < t < T}`。`Z_ij0`/`Z_ijT` 结构固定，任何配置都不释放；短期 Y 任何配置都不释放。

## 研究空间分解（分母均为 `|J_r|`）

| 项目 | 数值 |
|---|---:|
| 连续 LP 相对 S_r | +0.0534 |
| ABC 超 LP 的额外改善 | +0.0447 |
| ABC 相对 S_r 总计 | +0.0981 |
| **AB 超 LP 的额外改善** | **+0.1739** |
| **AB 相对 S_r 总计** | **+0.2273** |
| 参考：E@40 超 LP / 总计 | +0.1561 / +0.2095 |

**`AB`（20 秒、限制更死）的总改善 +22.73% 超过 40 秒完整 EMPTY 轨迹前缀的 +20.95%。** 瓶颈不在预算总量，而在放开哪些变量。

## 机制（实测的组改动，32 次平均）

- **A 是主要收益来源**：单独释放 A 得 `G_extra` +14.90%，平均改动 58.8 个 A 变量。
- **B 小但真实**：`AB` 比 `A` 在 7/8 实例更好（平均 +2.49%）。**不因 B 单独只有 +4.09% 就删掉它。**
- **加入 C 改变了搜索表现（方向变差）**，但**原因未确定**。

### 三条已收窄的表述（初版说过头了）

- **不能说"C 抢占了 B 的搜索资源"**：变量改动次数是**最终解**的属性，**不是搜索过程的资源分配记录**。可说的只是"加入 C 改变了搜索表现"。
- **不能由 `G_A + G_B > G_AB` 证明作用重叠**：A 与 AB 均**未证最优**（0/32），该不等式可能同时受限时求解影响。
- **AB(20 s) 与旧 E@40 的比较只能作历史描述**：**起点不同**（AB 从 LP 启动、E@40 从 S_r 启动），不能据此单独断言"瓶颈不在预算总量"。本轮有力的是**同起点同预算**的 AB—ABC。

## 廉价基线：`BC`（不可遗漏）

| 配置 | 证最优 | 平均总耗时 | `G_extra`（超 LP） |
|---|---:|---:|---:|
| B | 32/32 | 0.32 s | +0.0409 |
| C | 32/32 | 0.24 s | +0.0196 |
| **BC** | **32/32** | **0.92 s** | **+0.0611** |

`BC` 的 `G_extra` 是 **+6.11%**（相对 LP）；它的 `G_restrict`（相对 ABC）才 **+1.64%**——两个数不能混用。质量—时间权衡是必须保留的结果：`AB` 的 +17.39% 需要 20 秒满预算（0/32 证最优），`BC` 用不到 1 秒。

## 来源与改善必须分开统计

`final_source = solver` **不代表严格改善**：224 次中 solver 胜出 224 次，但**严格优于该次 LP 的只有 172 次**（52 次与 LP 相同，其中 21 次精确相等，**0 次劣于 LP**；判定容差 1e-9 相对）。逐配置严格改善数：A 32/32、**AB 32/32**、BC 28/32、B 24/32、C 20/32、ABC 13/32、AC 13/32。

## 关键边界（勿过度解读）

- **限时组合效果**：目标值未收敛（多数以 `Time limit reached` 结束），AB 与 ABC 的差距是 **20 秒内的搜索效果差异**；给 ABC 更多时间可能追平/反超。"释放 C 有害"**仅指该预算下**。
- **不能用限时失败证明子集不够**，也不能用 AB 的优秀证明 C 不必要（无最优值或有效下界支持）。
- ABC 在 **4/8** 实例上仍严格优于 LP ⇒ 完整 EMPTY 并非无效，只是本预算下不如 AB。
- `G_extra`/`G_restrict` 是相对 `|J_r|` 的**相对差，不是最优性间隙**。
- 二元配置仍只来自 S_r 一条分支；起点固定为 09A 的 LP 解；从 `S_r` 启动的旧 EMPTY 只作历史参考。
- 限于 large 尺度、16 个冻结状态、20 秒预算、highspy 1.15.1 单线程。

## 执行与完整性

- 224 次 MIP = 16 状态 × 7 配置 × 2 种子；wall 2785 s ≈ 46 分钟。
- **每次逻辑运行各自重跑那个廉价 LP**（约 0.1 s），避免 Stage 07 的共享前缀计时缺陷；**224/224 次 LP 目标值与 Stage 09A 一致**；MIP 授予 19.96–19.98 s。
- 未释放二元变量固定为 S_r 的规范化值（最大规范化误差 1.77e-14）；κ 与固定条件参考始终是 S_r。
- 输出取 **{solver, `S_LP`, `S_r`}** 中最优有效者；实测 **224/224 由 solver 胜出**，从未退回较差的 `S_r`。
- `stage09b_savecheck.py`：224 个方案全部重验（原模型、κ、**未释放二元变量仍在 S_r**、短期 Y 未动、结构固定未动、组翻转计数一致、输出规则、预算守恒），**最大约束违反 0**。
