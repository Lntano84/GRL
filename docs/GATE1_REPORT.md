# Gate 1 报告：overexposure 换场景的实证判定

> 日期：2026-09-16（v2，含 Gate 1a'' / 饱和曲线 / RR 结构性结论）
> 归属：DASFAA 2027 计划 W3 的生死线实验
> 结论（v3）：**1a / 1a' / 1a'' 都是"尺度正确但区间错误"的测量。**
> 真正结论：**在 `|S|/n ≥ 20~40%` 的饱和区间，度数排序能力确实反号（Gate 1c v3）**；
> **RR 在该模型上结构性不可用（Gate 1d）**；**GRL 的对手是无训练的 `delta2`（Gate 2）**。

**核心结论（v3）**：

1. ✅ **用户最初的假设成立**："高度数 hub 会把自己的邻域推过 `θ^τ`，度数变成反信号" ——
   **在 `|S|/n ≥ 20~40%` 的饱和区间，三张图一致证实**（`ρ_degree` 全部反号）。
   1a / 1a' 失败的原因是它们在 `|S|/n ≈ 0` 区间测，**是尺度用错，不是假设错误**。
2. **RR 在该模型上不是"变慢"而是"无法构造"**：正激活要求 `δ ≥ θ^κ > 0`，
   阈值窗口均匀采自 2D simplex，`θ^κ = 0` 是零测集 ⇒ 反向可达没有锚点，RR 集恒为空；
   且给定窗口后 `δ` 是 `S` 的确定性函数，**不存在可采样的逐边随机结构**。
3. ⚠️ **`delta2` 在所有区间都优于度数**，所以 GRL 的对手是 `delta2`，不是度数。
   `delta2` 是**无训练的两跳解析公式**，GRL 必须证明它能在此基础上再进一步（Gate 2）。
4. **权重口径**：模型**要求**入权归一化到和为 1。
   均匀 `p=0.01` 会使 `δ` 上限仅 ~0.15，级联几乎不发生，阈值**结构上不可达**，
   该模型与均匀稀疏权重**本质不兼容**。

**一句话**：立项理由 = **"RR 在定义域上不适用"**（可证明，不依赖非单调性）；
性能目标 = **"超过无训练的解析基线 `delta2`"**；
而"度数失效"这条**在正确的区间下是成立的**，可以作为 motivation 的辅助论证。

## Gate 1a：度数信号未失效 ❌

`docs/results/overexposure_degree_signal_20260916.json`

设置：NetHEPT，9 个 context（k∈{5,10,20} × 3），每 context 采样 **800 个候选**，40 次 MC 配对估计。

| 模型 | Spearman(度数, 真实边际增益) | std | top1 一致率 |
| --- | --- | --- | --- |
| IC | 0.8848 | 0.0150 | 0.111 |
| **overexposure** | **0.8882** | 0.0100 | **0.667** |

按预算分层：

| k | IC Spearman (top1) | overexposure Spearman (top1) |
| --- | --- | --- |
| 5 | 0.8817 (0.333) | **0.8976** (1.000) |
| 10 | 0.8738 (0.000) | **0.8848** (0.667) |
| 20 | **0.8991** (0.000) | 0.8823 (0.333) |

### 解读

**原假设**：高度数 hub 会把自己的邻域推过 `θ^τ`，因此度数在过度暴露下变成反信号。

**实测**：不成立。度数在过度暴露下**略好、更稳定**，且"最高度数 = 最优候选"的一致率从 11% 升到 67%。

**机制线索**（`scripts` 侧的一次性统计）：NetHEPT 的**入边权被归一化到和为 1**（`Σ_u ω_uv = 1`），所以
- 决定"是否过度暴露"的是节点的**入度**；
- 决定"种子影响力"的是节点的**出度**；
- 二者互不干扰，因此出度信号不会被过度暴露破坏。

⚠️ ~~这是**数据相关的**结论。若换用非归一化权重的图（如纯 IC 的 `p=0.01`），过度暴露会更剧烈，度数可能真的失效。~~

**❌ 上面这句 v1 的推测是错的，实测方向完全相反（见 Gate 1c v3）。**
换用均匀 `p=0.01` **不会**让过度暴露更剧烈，而是让它**完全消失**：
`δ` 实际上限只有 0.151（最大入度 60 × 0.01 = 0.6 是理论上限），
级联几乎不发生，负边际占比 **0/120**。**阈值在结构上不可达。**
真正让度数失效的变量是**种子比例 `|S|/n`**，不是权重是否归一化。

### 一条重要的方法学限制

**本诊断测的是"度数能否预测静态随机候选的边际增益"，而不是"在具体状态 `S` 下度数能否做条件排序"。** 后者（记为 Gate 1a'）才是状态感知预测器的直接对手。9/5 的记录显示状态感知监督把 same-candidate 跨状态 Spearman 从 0.267 提到 0.908 —— 说明条件排序确实是另一回事。

**⚠️ 事后更正（见下文 1a''）**：1a 的候选池是 `rng.sample(pool, 800)`，即**从全图均匀抽样**。NetHEPT 度分布重尾，这种池子里绝大多数是低度节点，"度数 vs 真增益"的高相关其实在测**池子构成**（高度节点增益大这条全局规律），而不是排序能力。**1a 和 1a' 用的是同一个有偏口径，因此二者的"未通过"都不是对状态感知的公正检验。**

## Gate 1a'：均匀池下的条件排序——未通过，且暴露了口径问题 ❌

`docs/results/overexposure_conditional_ranking_20260916.json`

设置：NetHEPT，k∈{10,20}，各 5 个 context，每 context **400 个均匀随机候选**，固定具体 `S`，30 次 MC 配对估计。

| 模型 | Spearman(度数) | Spearman(状态感知) | Δ |
| --- | --- | --- | --- |
| IC | 0.8806 | 0.8300 | **−0.0506** |
| overexposure | 0.8801 | 0.8787 | **−0.0014** |

**判定：未通过。** 更早的一次小规模运行（3 context、200 候选）曾给出 `+0.0148`，**不可复现**。

### 为什么这个测试是错的

| 问题 | 说明 |
| --- | --- |
| **池子偏差** | 均匀随机池中高度枢纽很少落入，"度数"占的是池子构成的便宜 |
| **与部署口径不符** | 真实架构是 `Retriever(度数) → Top-M → Reranker`，重排序器**永远看不到**全图均匀样本 |
| **数学口径错误** | 旧评分器把最短路径 reach 概率与概率增量**相乘**（`contribution * (after - before)`），这不是任何期望量 |

三条都修掉之后就是 Gate 1a''。

## Gate 1a''：真实检索池内的条件排序——通过 ✅

`docs/results/overexposure_pool_ranking_20260916.json`
`scripts/experiments/evaluate_overexposure_pool_ranking.py`

设置：NetHEPT，k∈{10,20} × 6 个 context = **12 个上下文/池**，每上下文 400 个候选，30 次 MC 配对估计。
两种池：**`degree_pool`**（按出度取头部再抽，即部署口径）与 **`uniform_pool`**（对照，复现 1a' 的偏差）。

### 评分器

| 名称 | 定义 |
| --- | --- |
| `degree` | 出度。现任基线，完全不看状态 |
| `bfs_v1` | Gate 1a' 的旧评分器，**保留以证明修正的必要性** |
| `delta2` | 修正后的两跳期望：`ΔE_w(v) = ω_wv·(1 − E_S(v))`，`score(w) = Σ_v [g(E_S(v)+ΔE_w(v)) − g(E_S(v))]`，`g(e)=2e(1−e)` |
| `random` | 下界 |

### 结果（degree_pool，部署口径）

| 评分器 | Spearman | recall@10 | gain_capture |
| --- | --- | --- | --- |
| degree | 0.6541 | 0.5000 | 0.7839 |
| bfs_v1（旧口径） | 0.5286 | 0.3333 | 0.5879 |
| **delta2（修正）** | **0.8439** | **0.5833** | **0.8476** |
| random | −0.0019 | 0.0250 | 0.1810 |

配对差异（bootstrap 95% CI，12 个上下文）：

```
Δspearman_delta2 = +0.1899   CI [+0.1781, +0.2018]   ← 相对提升 +29%
Δcapture_delta2  = +0.0637   CI [+0.0271, +0.1026]
Δrecall_delta2   = +0.0833   CI [+0.0250, +0.1500]
Δspearman_bfs_v1 = −0.1255   CI [−0.1536, −0.1003]   ← 旧口径显著有害
Δcapture_bfs_v1  = −0.1960   CI [−0.2558, −0.1329]
```

### 结果（uniform_pool，对照）

| 评分器 | Spearman | recall@10 | gain_capture |
| --- | --- | --- | --- |
| degree | 0.8823 | 0.5750 | 0.8323 |
| bfs_v1 | 0.8882 | 0.3917 | 0.6798 |
| **delta2** | **0.9624** | 0.6333 | **0.8989** |

关键对比：在 `degree_pool` 里度数的 Spearman 掉到 **0.654**，在 `uniform_pool` 里是 **0.882** ——
**同一张图、同一个目标，只换池子，度数信号就掉了 0.23。** 这直接证明 1a/1a' 测的是池子构成而非排序能力。

同时 `delta2` 在两种池里都领先，且在对照池里达到 **0.962**，说明它不是靠池子偏差取胜。

### 这件事对 GRL 的意义

`delta2` 是**无学习的解析公式**，不需要训练。所以：

- ✅ **好消息**：状态条件化确实有可度量的价值，且方向与 `Retriever → Top-M → Reranker` 架构完全兼容。
- ⚠️ **警告**：**"用 GNN 学一个更好的评分器"这个卖点被削弱了** —— 一个两跳解析式已经拿到 +0.19 Spearman。
  GRL 必须证明它能超过 `delta2`，而不是只超过 `degree`。

## Gate 1b：顺序/自适应决策价值很大 ✅

`docs/results/overexposure_sequential_value_det_20260916.json`（确定性）
`docs/results/overexposure_sequential_value_stoch_20260916.json`（随机）

三个策略（区分"顺序"与"自适应"，避免把二者混为一谈）：

| 策略 | 含义 |
| --- | --- |
| `static_degree` | 按出度取 top-k，不看状态、不看顺序 |
| `nonadaptive_greedy` | 用贪心选 size-k 集合，但**在级联开始前一次定完** |
| `adaptive_greedy` | **每步观测实际级联状态**后重新选择 |

设置：k∈{5,10}，4 trial，候选池 80，12 次评估 MC。

### 确定性模式（完美观测）

| 策略 | 平均 spread | std |
| --- | --- | --- |
| static_degree | 67.72 | 23.35 |
| nonadaptive_greedy | 56.94 | 21.76 |
| **adaptive_greedy** | **85.21** | 26.13 |

```
adaptive - nonadaptive = +28.27  (+58.0%)   ← 8/8 trial 全胜
nonadaptive - static   = -10.78             ← 不用状态的贪心反而输给度数
```

### 随机模式（每步只有噪声观测）

| 策略 | 平均 spread | std |
| --- | --- | --- |
| static_degree | 15.15 | 4.87 |
| nonadaptive_greedy | 14.85 | 5.47 |
| **adaptive_greedy** | **16.83** | 4.75 |

```
adaptive - nonadaptive = +1.98  (+17.4%)    ← 6/8 trial 胜
nonadaptive - static   = -0.29
```

### 解读

1. **自适应优势在两个模式下都成立**，且随机模式下仍有 +17.4% —— 这是更接近现实的设定（观测有噪声），说明优势不是"完美观测"的产物。
2. **`nonadaptive_greedy` 打不过 `static_degree`**（-10.78 / -0.29）。这是很有价值的负面结果：**在过度暴露下，不理解状态的贪心规划是有害的**，因为它按"平均情况"优化，而实际收益高度依赖具体实现在哪个曝光区间。
3. ⇒ **这正是学习型状态的战场**：不是"预测谁更强"（度数已经够好），而是"**判断当前状态处于哪个区间**"。

### 对论证的影响（v3）

✅ **用户最初的假设成立，只是区间用错了。**
> "高度数 hub 会把自己的邻域推过 `θ^τ`，因此度数在过度暴露下变成反信号"

**在 `|S|/n ≥ 20~40%` 的饱和区间，这个假设被三张图一致证实。**
1a / 1a' 之所以失败，是因为它们在 `|S|/n ≈ 0` 的区间测——那时度数当然还是好信号。

⚠️ **但必须同时承认**：`delta2` 在**所有区间**都优于度数，包括未饱和区间。
所以"学习型模型有空间"这个论证要建立在 **`delta2` 之上**，不是建立在度数之上。

### 权重口径的重要澄清（v3 新增）

模型**要求**入权归一化到和为 1，这不是人为加工：
- 正激活窗口要求 `δ` 能落进 `[θ^κ, θ^τ]`，所以权重必须足够大，
  使"合理数量的激活入邻居"就能把 `δ` 推进窗口；
- 用**均匀 `p=0.01`** 重测 NetHEPT：`δ` 实际上限只有 **0.151**
  （因为最大入度 60 × 0.01 = 0.6 是理论上限，实际远达不到），
  **级联几乎不发生**（平均边际增益 1.046 ≈ 只有种子自己），
  负边际占比 **0/120**。**阈值在结构上不可达。**

⇒ **均匀稀疏权重与该模型本质不兼容。** 论文自己的数据集
（Congress-Twitter 权重和=1、平均度 55.95）本来就带归一化权重。
**对标实验必须用归一化权重，不能"为了公平"改成均匀 p。**

## Gate 1d：RR / 反向可达结构性不可用 ✅

`scripts/experiments/evaluate_overexposure_monotonicity_rr.py`

这是对"RR 到底能不能适配 CCIM"的**直接实测回答**。

### 实测（NetHEPT，15233 节点）

```
nodes whose window includes 0    : 0  / 15233
RR-set size（300 次反向 BFS）     : min=0  median=0  mean=0.0  max=0
RR-set 占全图比例                 : 0.0000%
TIM 式估计  n · Pr[S ∩ RR ≠ ∅]   : 0.0
真实 Monte-Carlo σ(S), |S|=50     : 111.9
```

**RR 集恒为空。** 经典恒等式 `E[I(S)] = n·Pr[S∩RR≠∅]` 退化为 `0`，而真实 spread 是 111.9 ——
**恒等式的前提不成立，估计量空转。**

> 注意口径：先前的一次探测把**源点自身**计入 RR 集，得到"估计 = 15233、高估 164 倍"。
> 那是错的口径 —— 在 δ=0 时非种子节点不可能正激活。排除源点后 RR 集为**空**，
> 这比"高估"更干净地说明：**反向可达关系根本不存在。**

### 根本原因（两层）

**第一层——没有锚点。** 正激活条件是 `δ(v) ∈ [θ^κ_v, θ^τ_v]`。
阈值窗口从 2D simplex `{(κ,τ) : 0 ≤ κ ≤ τ ≤ 1}` 上**均匀采样**，
所以 `θ^κ_v = 0` 是**零测集**（实测 15233 个节点中 **0 个**满足 `κ ≤ 0`）。
于是 `δ = 0` 的节点正激活概率为 **0**。
而反向可达性要求"零入边影响也能被激活"作为传播起点 —— **这里不存在**。

对比：IC 里单条边成功即可传播；LT 里 trigger set 可以只含一个已激活入邻居。
二者都有非平凡的"零影响激活"通道，这正是 RR 采样的起点。

**第二层（更根本）——不存在可采样的随机结构。**
经典 RR 恒等式依赖**逐边独立的随机结构**（IC 的 live-edge、LT 的 trigger set）。
而本模型的

```
δ(v,t) = Σ_{u ∈ A^in_t(v)} ω_uv
```

其中 `A^in_t(v)` 是**"曾经正激活过"的入邻居集合**
（论文原文：*"also contains those nodes that were positively activated but later negatively activated"*）——
这是一个**集合函数**。

> **给定阈值窗口后，`δ` 完全由 `S` 决定；全过程唯一的随机性就是那次窗口采样，没有任何逐边随机性。**

所以既不能采 live-edge，也不能采 trigger set。**RR 的约简对象不存在** ——
这不是效率问题，是**定义域**问题。

### 交叉印证：论文自己的定理

- **Theorem 5** 只给出 **`γ/k`** 近似比（而非 `(1−1/e)`），且证明用 `σ(S_Ω) ≥ σ({v})`（弱单调性）。
- **Lemma 2 / Theorem 6**：它用 `σ^κ(·)`、`σ^τ(·)` 两个**单调且次模**的 LT 函数去夹逼非单调目标，
  `λ(S) ≥ σ(S)`，再对**单调代理**做优化。
- **论文的求解路径本身绕开了非单调目标。**

### 对 GRL 提案的意义

这一条是**最强的立项理由**，且**不依赖非单调性**（因此不受 Gate 1c 影响）：

> RR 及其全部变体（TIM / TIM+ / IMM / OPIM / SSA / D-SSA）在该模型上不可用，
> 因为恒等式所需的随机结构不存在。因此**不存在 RR 基线**，
> 也**不存在 GPU 并行 RR（gIM / cuRipples / PaC-IM）的 220×~790× 速度优势**可继承。

⚠️ **同时必须承认**：论文的 `λ(S)` 单调代理**是一个合法的 RR 落点** —— 对 `σ^κ` / `σ^τ` 可以正常跑 RR。
所以完整表述应为：

> **"RR 只能求解一个单调上界 `λ(S)`，而 `λ(S) ≥ σ(S)` 且 Theorem 5 只保证 `γ/k`；
> 直接用 RR 的覆盖语义求解会让估计量空转（RR 集为空）。"**

这个对比本身就是很好的实验素材。

## 对论文论证的修正（v3 重写）

### 必须放弃的说法

> ❌ ~~"度数在过度暴露下失效，所以需要学习型方法。"~~
> **更正**：这条**其实成立**（Gate 1c v3），但**只在 `|S|/n ≥ 20~40%` 的饱和区间**。
> 1a / 1a' 失败是因为它们在 `|S|/n ≈ 0` 测。**必须明确写出区间，否则会被审稿人用
> 低覆盖率实验反杀。**

> ❌ ~~"目标非单调，所以 RR 失效。"~~
> Gate 1c v3 显示 Congress-Twitter 确实非单调，但 Wiki-Vote / NetHEPT 在采样区间内单调。
> **不能把"非单调"当作 RR 失效的理由** —— RR 失效是**定义域**问题（Gate 1d），
> 与非单调性无关。把两者混在一起会被逐个击破。

> ❌ "用均匀 `p=0.01` 更公平。" **该模型与均匀稀疏权重不兼容**（阈值结构上不可达）。

### 可以主张的说法（按强度排序，v3）

> ✅ **(A) RR 结构性不可用。** 正激活要求 `δ ≥ θ^κ > 0`，而 `θ^κ = 0` 是零测集，
> 因此反向可达没有锚点、RR 集恒为空；且给定窗口后 `δ` 是 `S` 的确定性函数，
> 不存在可采样的逐边随机结构。**RR 恒等式的定义域不覆盖本模型。**
> —— **不依赖非单调性，是最强的立项理由。**

> ✅ **(B) 度数在饱和区间反号。** `ρ_degree` 三图一致从正转负
> （`+0.912→−0.141`、`+0.792→−0.229`、`+0.472→−0.397`），
> 负边际占比最高 **50.8%**（Congress-Twitter, `|S|/n=10.1%`）。
> **必须标注区间：`|S|/n ≥ 20%`。**

> ✅ **(C) 状态条件化有可度量的价值，且 `delta2` 全程为正。**
> `delta2 − degree` 的 Spearman：**+0.3003 / +0.2685 / +0.1332**；
> gain_capture：**+0.2995 / +0.2165 / +0.2161**。

> ✅ **(D) 静态规划失效、自适应显著更好。** `nonadaptive_greedy` < `static_degree`（−10.78），
> `adaptive_greedy` 比 `nonadaptive_greedy` 高 **+58.0%**（确定性）/ **+17.4%**（随机观测）。

### 论文结构上的影响（v3）

- §1 motivation：**以 (A) 开场**（"RR 为什么在这里没有定义"），(B) 作为辅助；
- §3：用 Gate 1d 的实测（RR 集为空、估计量为 0）+ Gate 1c 的**比例扫描**曲线，
  **并诚实说明论文的 `λ(S)` 单调代理是一个合法 RR 落点**，把对比做成卖点；
- §4：方法卖点 = **相对 `delta2` 解析基线的增量 + 摊销成本**（Gate 2），不能只报相对 `degree`；
- §5 实验必须包含：`degree`、**`delta2`（无学习，关键对手）**、`nonadaptive_greedy`、`adaptive_greedy`，
  且**必须扫 `|S|/n`**，并把饱和区间单独报告。

### ⚠️ 对 GRL 提案的核心风险（Gate 2）

`delta2` **是两跳解析公式，不需要任何训练**，却：
- 在**所有区间**优于度数（Gate 1c v3）；
- 在饱和区间是唯一保持正相关的评分器（度数已反号）。

⇒ **"用 GNN 学一个更准的评分器"这个卖点必须建立在超过 `delta2` 之上。**
只超过 `degree` 不足以支撑一篇 DASFAA。这是下一道生死线。
