# 精确方法与可引用性质

## 信息权限和目标

输入为当前公开观测、基础控制器传入的base action、静态动作库与原变电站元数据。只有实际派发的`obs.simulate`反馈可进入选择；未查询候选的成绩不能提前看到。

候选处理沿原合格路径：按当前规则筛选、去掉断线端点不合法的set-bus项，对当前实际组合向量规范化，保留原ID到代表的aliases。排序是已有作者教师频次降序（库ID升序），不是随机顺序。

可接纳条件：`0 < rho_future < min(rho_current, passed_rho_threshold)`，预测未结束，无exception、illegal和ambiguous。选择键为`(float32(reward), -pool_id)`。实际整周benchmark成本与此键分开。

## 冻结搜索日程

1. 首批最多128代表，维护可接纳incumbent。
2. 首批池已耗尽或incumbent的rho<0.9，直接返回；这种返回不补全。
3. 否则以64一批补查。键改进使stale归零，否则加一。
4. 有incumbent且rho<0.9，或累计至少256且连续两批无改进时，结束批遍历；没有可接纳incumbent时继续到池耗尽。
5. 若扩展搜索结束、有incumbent且还有未查代表，取**该incumbent的原变电站**。查询此站所有原aliases对应、尚未查过的代表；继续按同一键更新incumbent。
6. 不递归补新incumbent的站，不重新购买已查代表。没有incumbent时返回无拓扑提案，后续由原控制器处理。

128/64/256/2为既有冻结配置，不是数学最优参数，也没有在封存集上扫参。最多仍可购买整个池，因此没有硬实时或亚线性最坏保证。

## 别名与补全集合

设代表集合为A，原ID到代表映射为rep(i)，原ID所属变电站为s(i)，扩展停止前的incumbent为a_C，已查询集合为C。

本轮补全目标为 `L = {rep(i) in A \\ C : s(i) = s(a_C)}`。这一定义包含物理等价alias，不要求各原ID的变电站标签与规范化代表完全相同。

补全前从C中可接纳项按键f选a_C。补全后从C并L中的可接纳项选a_after，故 `f(a_after) >= f(a_C)`。理由：a_C仍属于选择集，更新只在键更大时发生。

新增查询次数恰好为|L|；每代表最多一次，总次数不超过|A|。它不保证L外没有更好项，也不保证后续各时段成本单调下降。先验排序与被选站的物理含义为设计理由，不构成分解电网耦合的定理。

## 参照定义

- FULL：全部当前代表，按同一admissibility和f选。
- FIRST_SAFE_BEST：按相同顺序查到第一个严格可接纳rho<0.9项就返回；没有这种项则穷尽后取最佳可接纳。比SoftGNN基本版无safe时DoNothing回退更强，不是完整SoftGNN重现。
- NO_LOCAL：与FRAME同样的渐进／停止，只去掉步骤5。
- FRAME：全部步骤。

基础连续控制、恢复节奏、共享DC和safeQP缓存、初始环境／扰动规则、候选库与计时一致。候选搜索钩子的N1名称不代表完成全部线路的N−1认证。

## 成本定义

安装的`L2RPNSandBoxScore`以当前最大运行机组的成本系数乘能量项：损失、绝对实际调度、**弃电量的前后变化**、storage吞吐。时间因子为delta_t小时。公开状态账目在既定浮点容差内独立对账。

它是benchmark约定，不是总弃电能源或现实运营账单。稿件中首次使用“operational cost”时应说明这一点，避免将百分比转写成生产财政收益。
