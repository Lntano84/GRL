# SB01：SAT 求解器历史信息回放实验

## 结果概览

使用公开的 5,355×28 性能矩阵，隐藏每个求解器列依次作为新版本，共 28 个留出版本；每个版本使用 20 个固定抽样种子。每个种子从同一组 64 个先导实例与 128 个校正实例估计五种方法。未运行 SAT 求解器。

总体误差和误判率先在每个隐藏版本的 20 个抽样种子内汇总，再对 28 个版本等权宏平均。抽样重复不是独立新版本，也没有据此计算置信保证或显著性。

|---|---:|---:|---:|---:|---:|---:|
| 普通样本均值（P∪S共192次测量） | 259.24 | 325.77 | -107.27 | 33.2% | 0 / 0 / 28 | 1 / 3 / 24 |
| 最佳历史版本 + 原分组残差校正 | 123.80 | 153.65 | 4.40 | 15.5% | 6 / 0 / 22 | 5 / 16 / 7 |
| 最佳历史版本 + 全样本配对（192） | 108.90 | 135.11 | -2.61 | 15.0% | — | — |

## 新旧总体成绩比较

本留一列比较规则把每个新版本与其余历史列中的全局最佳者比较。无并列时，只有全局第一名被留出的一折会是真正更优的挑战者；因此本轮只有一个正例是比较器定义带来的覆盖边界。

全样本配对估计的宏平均 MAE 为 108.90，误判 84/560；原分组配对估计为 123.80、87/560。岭回归 MAE 为 106.31，比全样本配对低 2.38%；但总误判为 85/560。按 28 个版本计，岭回归 MAE 更低 / 相同 / 更高为 16 / 0 / 12，误判更低 / 相同 / 更高为 8 / 15 / 5。唯一真实更优的新版本是 `Kissat_MAB_ESA`：全样本配对正确 10/20，岭回归正确 9/20。

最近的两折分别是 `Kissat_MAB_ESA` 对 `kissat-sc2022-bulky`，以及反向比较。它们是同一无序求解器对的两个留出方向，训练条件各异，但不是两个独立近差距案例；真实差距绝对值为 4.56 PAR-2 秒，约占比较器均分的 0.162%。这两折的平均误判率为全样本配对 50.0%、岭回归 55.0%。对这一极接近的求解器对，本批估计没有实现可靠区分，也未观察到岭回归改善判断。

| 隐藏新版本 | 最佳历史列 | 真实差距（PAR-2秒） | 普通均值误判率 | 原分组配对误判率 | 全样本配对误判率 | 最近历史误判率 | 岭回归误判率 |
|---|---|---:|---:|---:|---:|---:|---:|
| Kissat_MAB_ESA | kissat-sc2022-bulky | -4.56 | 35.0% | 35.0% | 50.0% | 45.0% | 55.0% |
| kissat-sc2022-bulky | Kissat_MAB_ESA | 4.56 | 50.0% | 35.0% | 50.0% | 50.0% | 55.0% |

本轮结论：合法历史信息明显改善了普通抽样估计；但充分利用全部已测数据的简单配对方法，已解释了大部分收益。固定岭回归没有显示出稳定的新旧判断优势，目前不足以支持增加模型复杂度。这里只描述这批比较的结果，不把单一近差距求解器对外推为普遍表现。本结论限于固定样本的岭回归增强方案；成本敏感选例、截断策略和可靠停止尚未检验，因此不构成对整个方向的失败结论。

## 矩阵审计与估计定义

- 原始 CSV 为 1,621,990 字节（约 1.62 MB）；5,355 行、28 个求解器列、149,940 个成绩单元。实例 hash 唯一；benchmark 字符串有 60 个重复名，因此用 hash 标识抽样行。成绩没有空值，范围为 0 至 10,000。
- 矩阵含 41,471 个 10,000 sentinel（27.66%）。官方预处理将其转为 timeout 标记，并在名为 PAR-2 的平均评分中按 10,000 计分；SB01 不把 sentinel 当作一次真实耗时，也没有另乘 2。
- 每折的历史比较器是在其余 27 列上，使用全 5,355 行均分最低者。该历史成绩对所有方法已知，不读取留出的新版本整列。
- 普通样本均值直接对 P∪S 的 192 个已测成绩求均值。原分组配对、最近历史列和岭回归沿用先导预测加独立校正样本的残差校正式。新增全样本配对估计使用预先固定的最佳历史列和全部已测成绩：`μ_old + mean(y_i - y_old,i)`，其中 `i∈P∪S`；它无需先导拟合。
- 最近历史列以 P 上的平均绝对误差选择；岭回归使用 27 个历史成绩列，按 P 上列均值/标准差标准化输入与目标，固定 α=1.0，之后预测 R 并进行残差校正。不调参、不裁剪预测值。
- 模型输入仅含 27 列历史成绩和 64 个新版本先导成绩。benchmark 名称、实例 hash、SAT/UNSAT/unknown 标签和新版本未揭示成绩均未作为模型特征。
- 同一 seed 的 P 与 S 在所有留出列和估计器之间共用；每轮抽样无放回，P∩S为空。每个版本/种子/方法读取相同的 192 个成绩。
- 未揭示成绩扰动审计共 1,680 次预测对照（3 个预测方法×28 列×20 种子）；模型输入变化 0 次，预测变化 0 次。
- 每版本×种子测量成本固定为 192 个矩阵成绩。拟合、预测与最终校正计算的本机耗时分列记录；未把模型计算时间换算成 SAT 求解器评测省时。
- 公开数据仓库的 README 标注 CC BY 4.0；本报告保留来源、提交号与校验值，复用数据时应注明来源。
