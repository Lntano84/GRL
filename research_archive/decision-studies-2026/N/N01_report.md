## 结论

**手工图证明：指定的局部代理存在它无法表达的远距离条件偏好。**
四个两跳区域不交，三条边之后在 P、Q 汇合，真实偏好为 `δ_c = −6`、`δ_d = +6`。

**主实验没有观察到反转。** 在 ca-GrQc、当前传播参数和 40 个结构抽样比较下：
确认批点估计反转 **0** 个，确认反转 **0** 个。
逐世界条件差异**确实存在**（28/40 个比较至少有一个世界 `X_c ≠ X_d`），但经验均值很小。

**尚未建立**这种表达限制会产生实用选种损失，**更未建立**学习优势。
这不是宣布方向失败，也**不是**证明检验无效。

### 2.1 代理论证（局部依赖，修正版）

原文把两层局部代理写成模块化函数 `Σ̂(S) = Σ_{v∈S} φ(v) + const` 并用五个随机分数向量“验证”。
**这两步都已撤回**：一般两层 GNN 不是模块化函数，它能在感受野内表达种子间交互；
“逐节点输出后求和”也不等于“独立种子分数求和”。

正确的论证是局部依赖论证：固定图、参数、层数 `L` 与背景 `U`；
每个输出节点 `v` 的分数只依赖其 `L` 跳感受野 `N_L(v)` 内的种子指示。
若**没有任何**输出节点的 `N_L(v)` 同时包含 `{a,b}` 侧的候选与 `{c,d}` 侧的候选，则：

- 若 `N_L(v)` 只碰到 `{a,b}` 侧，把 `c` 换成 `d` 不改变 `N_L(v)` 内的种子，
  故 `φ_v(S_ac) = φ_v(S_ad)` 且 `φ_v(S_bc) = φ_v(S_bd)`；
- 若 `N_L(v)` 只碰到 `{c,d}` 侧，把 `a` 换成 `b` 不改变 `φ_v`，
  故 `φ_v(S_ac) = φ_v(S_bc)` 且 `φ_v(S_ad) = φ_v(S_bd)`。

两种情况下 `v` 对 `σ̂(S_ac) − σ̂(S_bc) − σ̂(S_ad) + σ̂(S_bd)` 的贡献都是 0，求和即得
`δ̂_c = δ̂_d`。手工图满足该假设（感受野互不相交），结论正是那个障碍。

**这个论证只证明指定四配置之间的关系，不证明模型对所有种子集合都可加。**
它也不涉及其他背景、其他预算或四配置之外的种子集合。它是**模型类层面**的论证：
只要官方 `SpreadPredictor` 属于该类就必然满足，但本轮**没有**在官方代码上实测。

> 官方前向**未完成**：本机无 torch/numpy/scipy，且 `github.com`、`raw.githubusercontent.com`
> 与 PyPI 索引全部不可达，无法取得 `yl489/rethink-IM` 的 `SpreadPredictor`。
> 按任务要求**没有用自己的简化网络冒充原实现**。

## 4. 修正后的数学说明

### 4.1 不交的是 `R2`，不是 `R`

原文的致命错误是：**两跳区域不交，不意味着第三跳及更远的可达区域不交。**
手工图就是直接反例（见 §2）。

### 4.2 含背景 `U` 的正确公式

令一个世界中的可达集合为 `A, B, C, D`，背景为 `W = R(U)`，则

```
X_c = |A \ (W ∪ C)| − |B \ (W ∪ C)|
X_d = |A \ (W ∪ D)| − |B \ (W ∪ D)|
```

记 `α = A\W, β = B\W, γ = C\W, δ = D\W`，相减得

```
X_c − X_d = |α ∩ δ| + |β ∩ γ| − |α ∩ γ| − |β ∩ δ|
```

原来把主导项写成 `|R(a)| − |R(b)|` 是**未经核验**的断言，现予撤回；
正确的主导部分是 `|A \ W| − |B \ W|`，修正项即上式。
要经验地核验这个分解需要逐世界的 `A, B, C, D, W` 集合，
而这些量**当时只在内存中计算、并未导出**（见 §7），所以本轮不对该分解作经验断言。

### 4.3 数据本身反驳了恒等式

两跳不交只约束**确定性前两跳**上的交集，而 live-edge 世界里的路径可以更长，
所以 `α ∩ δ` 与 `β ∩ γ` 可以非空。保存的数据给出了实测反例：

| 位置 | 数值 |
|---|---|
| 主实验 case 0，world 1000295 | `X_c = −20`，`X_d = −19` |
| 主实验 case 38，world 1001137 | `X_c = −36`，`X_d = −16`（差 20） |
| 确认批全体 | 68 / 81,920 个（世界，比较）对满足 `X_c ≠ X_d` |

这 68 个是**不恒等的实测反例**，不是“几乎恒等”的证明。
它们出现得少，可以解释**这批采样为什么难以发现反转**，
却不能证明反转被条件禁止。

| “冻结条件使检验无效 / 两跳不交排除真实反转” | 错误：不交的是 `R2` 而不是 `R`；手工图与 68 个非零差都是反例（§2、§4.3） |
| “同一对候选随背景 `U` 整体翻转符号” | **未被本实验测到**：40 个无序 `{a,b}` 对全部不同、无重复，所以跨例的符号差异只能说明**不同候选对优劣不同**，不能归因于背景（§6.1） |
| “N01-S 仍保证代理恒等” | 放开交叉不交条件后**同时移除了局部依赖论证的假设**，故 N01-S 不再携带任何代理恒等保证，不能用来判断原 GNN 的表达能力（§6.2） |
| `identical_by_construction` 标签 | 样本均值相等不能证明构造恒等，已改为纯描述标签 |
| 压缩文件“含四个集合原始激活数” | 实际上只导出了差值 `X_c, X_d`（§7） |

### 6.1 候选对唯一性核对

`{a,b}` 无序对：40 个，全部不同。`{c,d}` 无序对：40 个，全部不同。

### 6.2 N01-S 的地位

N01-S 是事后设计，其结构条件放开了交叉排除，因此
`δ̂_c ≡ δ̂_d` 的保证**不再成立**。即使在其中测到真实反转，
也不能直接说原 GNN 表达不了。**本轮不按 N01-S 方案扩展。**
其结果显示在 §8，仅作记录，不作为原命题的证据。

## 7. 数据留存的实际状态

**必须如实说明：** `N01_worlds.json.gz` 每个比较每个批次只保存了
`X_c`、`X_d`、两者是否相等的计数、以及最大 BFS 深度。
四个集合各自的逐世界激活数虽然在运行中计算过，但**没有导出**。

因此：

- §5 的统计重算是从**保存的差值**重算的，可信；
- §4.2 的集合分解（`α, β, γ, δ`）**无法**从留存数据核验，本轮不作经验断言；
- 原报告称压缩文件“含四个集合的原始激活数”，该说法**撤回**。

脚本 `run_diffusion.py` 已改为把逐世界的四个集合激活数一并导出，供后续轮次使用。

## 10. 限制

1. **官方前向未做**，代理论证停留在模型类层面。
2. **本设计对“实用决策损失”的检验能力有限。** 均匀抽取 40 个比较，
   适合先看现象是否**自然出现**，但**没有保证抽到接近决策边界的比较**——
   即主项接近零、耦合项非零的那些。这是原设计的局限，应明确承认，
   但不能用错误的恒等式去解释零结果。
3. **区间是近似 Monte Carlo 区间**，不是有限样本数学证书。
4. **单一图、单一协议**：只有 ca-GrQc、只有 IC 与 `p = 1/deg`、只有 k = 10。
5. **无第三方库交叉验证**：环境没有 networkx/numpy/scipy。
6. **`m/n` 不是后悔值**，只是两侧偏好中较小一侧的幅度。
7. **未建立实用选种损失，更未建立学习优势。**

---

## 11. 定位与下一步

可以保留的结论是：

> 手工图证明：指定局部代理存在不能表达的远距离条件偏好。
> 主实验在 ca-GrQc、当前传播参数和 40 个结构抽样比较中，
> 没有观察到点估计或确认反转；逐世界条件差异存在，但经验均值很小。
> 尚未建立这种表达限制会产生实用选种损失，更未建立学习优势。

下一步是否值得设计一个**仍保留代理不可辨识条件、同时更贴近决策边界**的实验，
在本轮之后另行决定。本轮止于修正证据解释，不增加样本、不换条件、不训练。
