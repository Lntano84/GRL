# GRID318 搜索赢家的一步预测复用

搜索器已评估选中动作，上层 LJN 随后对合并后的动作再做一步预测。本次固定只查这一次直接交接。两批回放中，全部 1,494 次有选中动作的调用均可重建出逐字节相同的联合动作。可覆盖的预测量约为 0.11% 至 0.13%，并且 208、261 和原启发式都有。暂不把这处优化列为扩大 261 优势的主线。

## 核查口径

范围与源码先发布于 3cd3646a。纳入 GRID291 全部 186 条已接纳回放和 GRID312 全部 24 条三臂回放，保留五月同样未完成整周的原记录，不混入 GRID291 到限部分条。两阶段各自保留原环境、模型池、日期及重复，汇总时不合成新的独立样本。

从每条搜索原保存 JSON 和状态向量读回基础动作、选中候选 ID 和原掩码。使用原动作库重建候选，核对返回动作及原已付费联合动作哈希。搜索预测的输入是候选加基础动作，上层同一观测的下一步校验使用基础动作原地加候选。按两个真实顺序分别合并，再比完整动作向量。逐调用核对原路径和归档哈希，逐回放核对候选查询数。未建环境、未调用模拟器，也没有模型预测或训练。

## 裁决

当前只证实同一观测下两次调用的动作向量相同。完整返回对象、模拟计数或状态变化仍需另行验证，现有日志也没有单独保存立即校验的完整返回。没有安装缓存或改原控制器。若今后确有运行工程需求，应在 208、261、原启发式上统一应用与验证这项复用。

原 GRID291 保存计时中，261 的优化器占 67.19%，全部预测占 24.60%，公开特征与模型推理合计约 0.17%。本次查到的复用量较小，即使工程验证通过，也只能解释共享开销的一小部分。保留 208/261 和已有差异证据。持续推进保持暂停。
