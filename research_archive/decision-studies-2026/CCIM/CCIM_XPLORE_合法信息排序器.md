## 1. 问题（固定不变）

**在最后一次调查前，只利用当时可见的信息，能否选出比 `degree_min` 更有价值的调查对象？**

## 2. 数据划分（结果之前落盘）

| 侧 | 状态数 | 生成种子 | 用途 |
|---|---:|---|---|
| 开发 | **20** | 沿用上一轮已看过的 `valprobe/0..19` | 训练可用 |
| 训练 | **40** | `rstates/1000..1039`（新） | 训练可用 |
| **留出评估** | **40** | `rstates/2000..2039`（新） | **方法冻结前不看收益** |

- 状态生成策略与上一轮**完全一致**：5 个固定免费种子 + 4 次均匀随机前沿调查（固定随机流），**不按收益筛状态**；
- 候选池仍 **≤8**，生成规则（必含 `degree_min`/`degree_max` 选择、其余固定种子补齐）与并列规则**不变**；
- **同一初始观测及其衍生轨迹必须在同一侧**（按初始种子分配，天然满足）；
- **重复的完整可见状态不得跨训练与评估两侧**：以「可见节点集合 + 可见边集合」为键去重，冲突则报错而非静默；
- 训练用 **20 开发 + 40 训练 = 60 个状态**；
- 这是**同图的新状态评估**，**不叫跨图泛化**。

## 3. 模型（固定，不扫描）

**L2 正则的 pairwise logistic 排序器**，单一配置，不扫模型、不加 GNN、不做 RL。

**输入（只取调查前可计算的量）**：

| 特征 | 说明 |
|---|---|
| 候选的**可见度数** | 观测子图内 |
| 可见邻居中**已调查**数量 | |
| 可见邻居中**未调查（前沿）**数量 | |
| 可见邻居之间的**连边数** | 局部连边 |
| 候选在观测子图中的**聚类系数** | |
| 邻居可见度的**均值 / 最大值** | 汇总 |
| **首次发现时刻**、**由多少次调查揭示** | 历史信息，原策略允许 |

**禁止输入**：真实度数、尚未揭示的邻居、调查后的信息、完整图嵌入、**节点 ID**。
**标准化**只用训练数据拟合。
**每个状态在训练目标中的总权重相同**（按该状态内对数取倒数加权），避免候选多的状态占更大权重。

**标签**：来自**训练状态上的特权模拟估计**（模拟批次）。这是**监督信号，不是部署输入**；其生成成本**单列**。

## 4. 主指标：留出状态上的**最终收益**

| 对照 | 用途 |
|---|---|
| **学习排序器 vs `degree_min`** | **唯一主比较** |
| 学习排序器 vs 随机调查 | 次要比较 |
| 特权选择程序 | 判断**新状态上是否仍有收益空间** |

所有方法选定动作后，**用独立确认批次**评价最终影响力；各方法采用一致的随机化与配对协议；**排序器不得看到确认结果**。
Pairwise accuracy、候选同选率**只作辅助**——排序准确率提高不一定意味着选中的动作更好。

## 5. 跑完如何决定（预先写死）

| 结果 | 决定 |
|---|---|
| 学习排序器 vs `degree_min` **确认收益明确为正** | 值得进入下一轮；**先证明监督排序有用**，再判断是否需要 GNN 或序列 RL |
| **特权选择仍有优势、排序器未建立优势** | **收益空间存在**，本轮合法信息方案尚未抓住；**不能宣布观测无信息** |
| 特权选择在**新状态上也没有明确优势** | 当前正例的**稳定性仍待确认**，**不追加复杂模型** |
