# Stage 18 — 无故障时名义计划是否也能被同一个 RINS 明显改善

**唯一问题（逐字）**：在不发生故障、仍限制短期计划改动的情况下，RINS-LP-ONE 能否用 20 秒明显改善冻结的名义计划？

**定位**：这不是换题，而是检查当前"故障重优化"实验是否**混入了大量原本就存在的计划改进空间**。本轮**8 次主运行**。

---

## 0. 结论

**能，而且幅度很大。命中预先固定的第 1 条。**

| 量（8 个名义实例，种子 1，20 秒） | 结果 |
|---|---|
| `G_total` 均值 | **+29.77%** |
| `G_total` 中位数 | +28.49% |
| 范围 | **+1.65% ~ +58.43%** |
| **严格改善（>0）** | **8/8** |
| **≥2%** | **7/8** |
| rho0.75 组 | **+34.70%**（4/4 为正） |
| rho1.10 组 | **+24.85%**（4/4 为正） |
| `G_continuous` | **+0.000000**（max \|·\| = 9.4e−16） |
| `G_binary` | **+29.77%**（即全部改善都来自二元部分） |
| 恒等式 `G_total = G_cont + G_bin` | **误差 0.00e+00** |
| 实际短期 Y 改动 | **1 或 4 位**（κ=4，全部合规） |

**⇒ 按预先固定的第 1 条**：**现有名义计划存在便宜、可重复利用的改进余地。下一步应先建立更强的名义计划版本，再检验故障后的方法表现；不能继续仅凭当前起点推导故障专属算法贡献。**

而且**改善几乎全部来自二元部分**（`G_continuous` 为 0）——这一点按预设也要如实区分。

**读法**：

- **8/8 严格改善，7/8 ≥2%**，两 ρ 组均为正（+34.70% / +24.85%）。
- **全部改善来自二元部分**：`G_continuous` 在 8/8 上都为 0（|·| ≤ 9.4e−16）。也就是说，**固定原二元配置后连续抛光已经做不动了**（`S_{N,LP}` 与 \(S_N\) 同值）；收益完全来自**改变二元配置**。
- 交付来源 8/8 都是 `solver`；`final_source=none`、选择错误、差于 \(J_N\) 的情况均为 **0**。
- 唯一接近门槛的是 `large_rho0.75_s4`（+1.65%），它的名义计划本来就最好（记录 gap 29.2%，也是全批最小的）。

### ⚠️ 更正 C44（用户逐变量重算后指出）：不能把改善归因于"那 1–4 位短期 Y"

我在本报告上一版写成"收益完全来自**改变少数短期 Y**（1–4 位）并据此重排生产/库存"，**这个机制表述不成立**。按用户的方法逐变量重算 Stage 18 的交付方案相对 \(S_N\) 的实际改动，我复现出完全一致的数字：

| 二元变量组 | 每实例改动数 | 均值 |
|---|---|---|
| 短期 Y | **1–4** | 3.6 |
| **远期 Y（A）** | **60–113** | 83.5 |
| 短期 Z（B） | **0–13** | 6.9 |
| **远期 Z（C）** | **39–49** | 44.8 |
| **全部二元合计** | **109–169** | 138.8 |

⇒ "只动 1–4 位短期 Y"作为**局部统计**成立，但**不能**据此说收益来自它。

**准确表述（已替换全文相应说法）**：

> **在短期 Y 只允许少量调整的条件下，同时重优化了大量远期 Y 和延续状态，取得明显收益；固定原二元配置后的连续抛光无法取得这些收益。**

**这个更正不影响主结论**（8/8 改善、均值 +29.77%、改善全部来自二元部分），**无须重跑**。

**另**：名义 gap 均值 **51.7%** 与用户此前给出的范围 **29.2%–73.8%** 不冲突——用户当时只给了范围，未给均值。

## 3. 与已记录的 gap 的关系（谨慎表述）

8 个名义计划的**记录 gap 范围为 29.2%–73.8%**（均值 51.7%）。

- 这些 gap 是**求解器自报的限时 gap**，**不能**证明计划差——gap 大也可能只是下界弱。
- 本轮给出的是**实测**：在无故障、κ=4、20 秒下，同一个 RINS 确实把这些计划改善了约 **29.8%**（对 \(J_N\) 归一化）。
- 两者**不必一致**，本轮也不据此推断"计划离最优有多远"。

---

## 4. ⚠️ 边界：本轮能说与不能说的

**能说**：

- 在**无故障 + κ=4 + 20 秒 + 种子 1** 下，RINS-LP-ONE 能明显改善这 8 个冻结名义计划（均值 +29.77%，8/8 严格改善，两 ρ 组均正）。
- 改善**几乎全部来自二元决策**（`G_continuous` = 0）。
- 因此**当前名义计划不是一个"已优化好"的起点**，它自身带有可被通用规则廉价利用的改进余地。

**不能说**：

- **不能认证名义计划接近最优**（反向也不成立：本轮发现的是"有改进余地"，不是"离最优多远"）。
- **不能直接拿本轮结果去减 Stage 17 的故障改善百分比**。两者**参考计划、归一化分母与可行域都不同**（本轮分母是 \(D_N=\max(1,|J_N|)\)，Stage 17 是 \(D=\max(1,|J_r|)\)；参考解一个是 \(S_N\)、一个是 \(S_r\)），**差值不能当作"故障专属收益"**。已写入 `stage18_runs.json` 的 `meta.warning`。
- 本轮只是**一个探针**：单个种子、单个算法、20 秒。它说明"存在改进余地"，**不构成对名义计划质量的完整刻画**。
- **不撤销 Stage 16–17 的方法比较**：那些比较是在**同一批状态、同一参考解 \(S_r\)、同一 κ 锚点**下做的，仍然有效。

## 5. 预先固定的解释方式：逐条裁定

| 预设情形 | 是否命中 | 依据 |
|---|---|---|
| **平均总改善 ≥2%、至少 6/8 实例严格改善、两 ρ 组均有正平均改善** | **✓ 命中** | 均值 **+29.77%**、**8/8 严格改善**、rho0.75 **+34.70%** / rho1.10 **+24.85%** |

| 基本没有改善 | ✗ | 8/8 都有改善 |

**⇒ 按预设第 1 条的含义**：

> **现有名义计划存在便宜、可重复利用的改进余地。下一步应先建立更强的名义计划版本，再检验故障后的方法表现；不能继续仅凭当前起点推导故障专属算法贡献。** 改善主要来自连续部分时也要如实区分——本轮**不是**这种情况：**全部来自二元部分**。

## 8. 下一步建议

1. **先建立更强的名义计划版本**（按预设第 1 条）。一个直接、便宜的候选做法：**把同一个 RINS-LP-ONE 探针直接用于生成名义计划本身**（同样的 20 秒、同样的 κ 锚点、多跑几个种子取最好者），得到 \(S_N^{*}\)，然后把整条"故障重优化"实验线**在 \(S_N^{*}\) 上重做一遍**。
2. **重做后的关键问题变了**：不再是"AB 是否优于 FULL"，而是**"在已经较强的起点上，故障后是否仍有非故障优化拿不到的、可被学习利用的缺口"**。这才是本文可能的新意所在。
3. **不建议**现在启动 GRL：**学习可利用的缺口尚未证实**。应先确认"存在故障专属缺口"这一基础条件，再谈学习。
4. **不建议**继续围绕 AB 扩展实验（Stage 16–17 已收束），也**不建议**再堆一串算法名称去验证"通用规则普遍支配固定规则"——那不是有限实验能证明、也不是我们需要证明的命题。
