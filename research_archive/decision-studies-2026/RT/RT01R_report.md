## 结论

> **RT-01 发现了大量缺少结束记录的作业，但尚未将真实完成延迟与失败、等待、部分任务结束
> 及记录缺失区分。ALLFINAL 仅补充了 956 条最终可观测标签，且主比较存在训练与预测特征
> 不一致。因此，本轮未建立预测信息价值上界，也未检验调度收益。当前数据处理协议尚不
> 具备支持研究裁决的资格。**

明确区分两件事：

| | 状态 |
|---|---|
| 「数据与检验是否合格」 | **不合格。** 协议需要重做后才能回答原问题 |
| 「这个方法是否有价值」 | **未判定。** 本轮没有产生能支持或否定它的证据 |

**这不是一个被可靠否定的选题，也不是一个已发现正证据的选题。**
上一版把它登记成「oracle 封死上限」，那个登记是错的。

## 2. 核心交付：标签资格表

这是本轮唯一决定「还能问什么」的产物。逐条记录按**它到底带什么时间信息**分类：

| 类别 | 定义 | 数量 | 占比 |
|---|---|---:|---:|
| **A_COMPLETE** | 所有任务都有结束时间，且作业状态为 Terminated | **732,355** | 69.38% |
| **B_COMPLETE_NONOK** | 所有任务都有结束时间，但作业非 Terminated | 1,218 | 0.12% |
| **C_PARTIAL** | 部分任务有结束时间，部分没有 | 25,508 | 2.42% |
| **D_NO_END** | 没有任何任务有结束时间 | 295,846 | 28.03% |
| **E_NEVER_LAUNCHED** | 也没有任务开始时间 | 574 | 0.05% |

### 每一类能支持什么

| 类别 | 能否作完成时长标签 | 说明 |
|---|---|---|
| A_COMPLETE | **可以** | 唯一无需额外假设就能作监督标签的类别 |
| B_COMPLETE_NONOK | **有条件** | 有结束时间，但作业未成功；只能作「本次尝试持续多久」的目标，**不能**当作成功服务时长 |
| C_PARTIAL | **不可以** | `max(end)` 只是下界；且必须先说明缺失任务为何没有结束时间 |
| D_NO_END | **不可以** | 究竟是在跑、静默失败、还是没记上，**表里无法分辨** |
| E_NEVER_LAUNCHED | **不可以** | 从未启动，属排队记录而非服务记录 |

### 对原比较的直接后果

上一版的训练标签是把「所有有结束时间的任务」取 `max(end)` 得到的，
这**静默混合了 A、B、C 三类**（A 732,355 + B 1,218 + C 25,508），并把 D 当成「没有标签」。
**在这样的标签上做的预测比较，不能被读作信息价值的上界。**

## 3. 修正后的比较（只用品类 A 标签）

参数：`T` = 轨迹第 41.4 天；测试窗口为 T 之后 10% 跨度内**开始**的作业，全部是品类 A。
特征对结果盲目（group / 任务角色 / user 哈希分桶、任务数）；训练与预测**使用同一个特征开关**。

- 品类 A 训练记录（T 前完成）：**372,694**
- 测试记录：**78,070**
- T 时点未完成（全类别）：**114,413**，其中 **113,457 (99.16%) 永远没有结束时间**

| 变体 | 可部署 | n_train | RMSLE | Spearman（并列修正） |
|---|:--:|---:|---:|---:|
| 只用已完成 | 是 | 372,694 | **1.8197** | +0.5064 |
| 已完成 + group 级删失特征 | 是 | 372,694 | 1.8139 | +0.5105 |
| 已完成 + 可救回的 956 条 | **否** | 373,650 | 1.8195 | +0.5065 |

**这些数字不构成信息价值的上界。** 理由：

1. 所谓「oracle」只覆盖了未完成记录的 0.84%；其余 113,457 条**在数据里就没有最终时长**，任何 oracle 都造不出来。
2. 即使标签补齐，某个固定岭回归的成绩也不是信息价值的数学上界——它只是特权对照。

## 4. 实现缺陷与修复

### 4.1 训练/预测特征不一致（已修）

原 `s4_oracle_regression.py`：训练时三个变体**都**加入 group 级删失特征
（`X.append(feats(j, share...))`），预测时只有第三个变体保留它，
另外两个把它置零。**这使 COMPLETED 不是定义中的「无删失特征模型」**，
第三个模型与它的比较也混入了特征定义差异。

修复方式：用同一个 `Design` 对象构建训练与预测矩阵，开关在两处一致。
并补了一个**能抓住该缺陷的测试**。缺陷的实际影响（同一批训练数据）：

| 训练开关 | 预测开关 | RMSLE | |
|:--:|:--:|---:|---|
| 开 | 开 | 1.8139 | 一致 |
| 开 | 关 | 1.8235 | **旧缺陷** |
| 关 | 开 | 1.8197 | **旧缺陷** |
| 关 | 关 | 1.8197 | 一致 |

偏差量级约 0.004 RMSLE，**相对很小但不能忽略**：它足以让「组级特征是否有效」
这类问题得到错误答案。

### 4.2 Spearman 未处理并列（已修）

原实现对排序位置直接取秩，并列值拿到任意不同秩。现在改为**平均秩**再算 Pearson。
测试覆盖：单调递增/递减且含并列 → ±1；常数序列 → 未定义；无并列时与教科书公式一致；
一个手算用例；以及「旧排秩器在有并列时确实会给出不同结果」（含符号错误的情形）。

> 注：`1 − 6Σd²/(n(n²−1))` 只在**无并列**时成立，含并列时平均秩 Pearson **就是**定义。

### 4.3 全部测试

`python RT_work/r3_estimator_lib.py` → **ALL TESTS PASSED**（**17** 项断言：8 项 Spearman、6 项特征开关与 guard、1 项 ridge、2 项收窄后的旧排秩器对照）。

### 5.1 随之更正的一个解释

上一版用「99.9% 整批同状态」论证陈旧记账。更正后：

| 口径 | 一致率 |
|---|---:|
| 全部桶（含 98.71% 的单记录桶） | 99.95% ← **无信息量** |
| **仅多记录桶** | **96.01%** |

**「同 group ⇒ 整组同状态」这一说法本身也不成立，一并撤回。**
官方定义只说同 group 的实例「输入/脚本/数据源等相似，**可视为重复实例**」，
它**不保证**同一次成功或失败，也**不保证**在冻结时刻具有相同的完成状态。
上一版把「记账异常必然导致」换成了「重复实例必然导致」，这是把一个未经证实的解释
替换成了另一个未经证实的解释。

现在只保留可观察的事实：**多记录桶的完成状态一致率是 96.01%，成因未确定。**
要判断成因，需要对照组或生命周期记录；本轮没有。

按 `group` 看集中度：92 个「≥200 到达」的 group 值里，55 个的未完成率 ≥ 2×总体；
但未完成作业落在前 10 个 group 值里的只占 **2.8%**。按 `workload` 看则**没有**集中度
（6 个值，无一达到 2×总体）。

## 6. 现在能说什么、不能说什么

**能说：**

1. 已开始记录中，**69.38%** 带有无歧义的完成时长标签（品类 A）。
2. **296,420** 条记录完全没有时长标签，
   且表内信息无法把它们判成「普通右删失」。
3. **25,508** 条作业只有部分任务有结束时间，其 `max(end)` 只是下界。
4. 上一版主比较存在已定位、已修复、已量化的实现缺陷。
5. 「未完成」在存档状态下是**混合物**（Failed 占 68%），不能整体当作删失样本。

**不能说：**

1. **不能**给出「利用未完成信息能带来多少预测价值」的上界——oracle 覆盖不到 0.84%。
2. **不能**说这个方向没有价值。
3. **不能**说调度不会改善——本轮没测调度。
4. **不能**说陈旧记账是主因——见 §5.1。

## 7. 下一步（本轮不做）

重新具备裁决资格，至少需要先解决三件事：

1. **把「未完成」拆成可判定的事件类型。** 需要失败/抢占的生命周期记录；
   若拿不到，就必须把方案限制在**只用品类 A** 的目标上，并明确不把它当删失问题。
2. **定义可测的目标。** 若目标是响应时间，就必须先解决等待时间不可观测的问题。
3. **换一个 oracle 可构造的检验。** 例如在同一时间窗内人为截断（把 T 之后的完成时间遮住），
   这样 oracle 覆盖率可控且已知，才能谈「信息价值」的量级。

第 3 条是关键：**本轮无法给出上界，不是因为没有价值，而是因为 oracle 在这个数据里造不出来。**
