# Stage 09A：连续变量重优化能解释多少收益？

## 唯一问题

> 当前修复计划的损失，有多少**无需改变任何换型或延续决策**，只重新优化生产、库存和销售损失就能消除？

求解

```
J_LP = min_{X,I,L} J(X, Y^r, Z^r, I, L)
```

**整个计划期的 Y、Z 全部固定为修复计划值**（含远期，t = 7…18）。

**这不是 EMPTY**，两者有本质区别：

| 方法 | 短期 Y | 远期 Y | Z |
|---|---|---|---|
| EMPTY | 固定 | **自由** | 除结构固定（`Z_ij0`、`Z_ijT`）外**自由** |
| 本轮固定二元 LP | 固定 | **固定** | **全部固定** |

所以本轮测的是**纯连续重优化**收益，不能继续把它称为 EMPTY。下面的结构统计会证明这个区分不是形式上的：EMPTY 的每一次改善都动了二元决策。

### 2.1 严格结论：16/16 状态都需要改二元决策

16 个 LP 全部**已证最优**。在这 16 个状态上，都存在**有效的 MIP 解**（E20 或 E@40）**严格优于已证最优的 `J_LP`**：

```
best MIP < proven LP optimum        16 / 16 状态
```

**因此：要在这些状态上达到 EMPTY/E20/E@40 已经取得的成本，必须至少改变一部分二元（换型／延续）决策。** 这不是"EMPTY 优于当前 LP incumbent"这种弱证据——LP 是**已证最优**的。

按预案第四条：LP 全部在上限内证得最优，因此**可以**下这个结论，不受"未证最优"的限制。

## 3. 结构统计：EMPTY 的改善伴随哪些决策变化

对 Stage 08 的 32 个 EMPTY 改善解（相对 `S_r` 计数，**无需新增求解**）：

| 变化类别 | 变化总数 | 平均每解 |
|---|---:|---:|
| 远期 Y（t = 7…18） | 3406 | ~106 |
| 短期 Z（t = 1…6） | 193 | ~6 |
| 远期 Z（t = 7…18） | 1747 | ~55 |
| 短期 Y | 0（EMPTY 按契约钉住） | 0 |

**32/32 个 EMPTY 改善解都至少动了一个远期 Y 或 Z。** 即 **EMPTY 不是连续变量方法**，这与第 0 节的区分一致。

**必须强调**：变化次数**不能证明**这些变量必须改变。上表只描述"收益伴随哪些决策变化"；严格的必要性判断来自 2.1 的 LP 最优值（已独立给出）。值得注意的是变化**集中在远期**（Y 与 Z 合计 5153 次，短期 Z 仅 193 次）——但这只是描述，不构成"远期变量更重要"的因果结论。

## 4. 结果如何决定下一步

| 预案 | 是否成立 | 证据 |
|---|---|---|
| LP 很快取得主要改善、接近或超过 E20 → 首先把连续重优化确立为基线 | **部分成立**：确立基线，且**在 10/16 状态上确实超过 E20**；但**没有**超过 E@40 | LP 均值 +5.34%、全部 0.14 s 内证优；vs E20 10/16 WIN（rho0.75 全胜）；vs E@40 0/16 |
| LP 改善有限，而 EMPTY 明显优于 LP 最优值 → 有证据说明收益需要改变二元决策 | **成立** | 16/16 状态 best MIP（E@40）< 已证 LP 最优 |
| 两种情况随状态变化 → 获得具体后续问题，但尚未证明学习可以预测 | **成立** | 连续部分占 0.1%–17.2%（跨状态 15 倍差异）；rho0.75 上 LP 赢 E20、rho1.10 上多数不赢 |
| LP 未证最优 → 不作"必须改变二元变量"的结论 | **不适用** | 16/16 已证最优 |

### 结论

1. **连续重优化应当成为基线，而且它的成本几乎为零**（均值 0.065 s vs MIP 的 20–40 s）。任何后续方法都应先扣掉这 +5.34%，再谈"搜索收益"。此前 Stage 06–08 里有一部分收益其实是连续调度改善——在 rho0.75 上这一部分甚至**超过了 20 秒 EMPTY 的全部交付**（10/16 状态 LP 赢）。
2. **但主要收益确实超出了廉价连续重优化**：修复计划损失的**约 5.3%** 可以不动任何二元决策拿到，**其余部分必须改变换型/延续决策**——在 16/16 状态上，E@40 交付的解都严格优于**已证最优**的 `J_LP`。所以"接下来值得学习或搜索的那部分收益"**是存在的**，没有被连续重优化吃掉。
3. **下一轮该问的具体问题**：收益的变化**集中在远期 Y 与 Z**（远期 Y 平均 ~106 次、远期 Z 平均 ~55 次，短期 Z 仅 ~6 次）。因此应研究**远期 Y、Z 中的哪些部分需要重优化**，而不是继续在短期邻域或搜索顺序上做文章。
4. **没有任何依据启动 GRL 训练。** 本轮只确立了一个廉价基线和一个更窄的后续问题。

## 5. 边界

- 16 个 LP 是 **LP**（二元全部钉住），其最优值是**固定该二元配置下的下界**，不是原 MIP 的下界；不能与 MIP 的 dual bound 混用。
- `G_continuous` 是相对**冻结修复成本**的相对差，**不是最优性间隙**。
- 每个状态只测了**一份**二元配置（修复计划的配置）。不同二元配置下的连续最优会不同；本轮**不枚举**，所以 +5.34% 是"沿修复计划这条分支"的连续收益。
- E@40 仍是**轨迹检查点**（同一条 40 秒运行的前缀），不是独立 40 秒运行。
- 结构统计的**变化次数不是必要性证明**；必要性结论来自 2.1 的已证 LP 最优值。
- 结论限于 **large 尺度、16 个冻结状态、该模型与成本口径**。
- 未调求解器参数、未加邻域规则、未训练模型、未生成新实例。
