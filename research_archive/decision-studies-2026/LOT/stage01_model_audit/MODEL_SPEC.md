## 1. 问题与假设

多产品、多机器、离散时段的能力受限批量规划（capacitated lot sizing），含换型成本与换型时间、机器容量、产品-机器兼容性、库存、销售损失、每批次最小生产量，以及**换型状态延续（setup carry-over）**。

约定与论文一致或按论文正文明确说明：

| 项 | 取值 |
|---|---|
| 时段 | $t = 1,\dots,T$，需求 $d_{it}$ 在决策时已知 |
| 销售损失 | 不转结为下一期欠单（no backlogging），$L_{it}\le d_{it}$ |
| 初始库存 | 参数 $I_{i0}$ |
| 初始延续状态 | $Z_{ij0}=0$（论文式 (1.13) 显式固定） |
| 换型状态延续 | 同一机器同一产品至多连续延续一次 |
| 兼容性 | $w_{ij}=0$ 时该机器不能生产该产品 |

## 2. 变量

| 变量 | 类型 | 含义 |
|---|---|---|
| $X_{ijt}\ge 0$ | 连续 | 产品 $i$ 在机器 $j$ 时段 $t$ 的生产量 |
| $I_{it}\ge 0$ | 连续 | 产品 $i$ 在时段 $t$ 末的库存 |
| $L_{it}\ge 0$ | 连续 | 产品 $i$ 在时段 $t$ 的销售损失量 |
| $Y_{ijt}\in\{0,1\}$ | **二元** | 机器 $j$ 在时段 $t$ 为产品 $i$ 做了换型 |
| $Z_{ijt}\in\{0,1\}$ | **二元** | 产品 $i$ 在机器 $j$ 上从时段 $t$ 延续到 $t+1$ |

$Z_{ij0}$ 是"上一期末的延续状态"，按 (1.13) 固定为 0。

## 3. 目标函数 (1.1)

$$\min \sum_{i=1}^{N}\sum_{t=1}^{T}\Big[\sum_{j=1}^{M}\big(f_i Y_{ijt}+p_i X_{ijt}\big)+h_i I_{it}+l_{it}L_{it}\Big]$$

四类成本：换型、生产、库存、销售损失。目标函数直接由变量值计算，**不需要任何神经网络近似**。

## 4. 约束

按论文编号，写成本实现所使用的标准型 `row_lb <= A x <= row_ub`：

| 编号 | 含义 | 原始形式 | 实现形式 |
|---|---|---|---|
| (1.2) | 库存流平衡 | $I_{i(t-1)}+\sum_j X_{ijt}+L_{it}=d_{it}+I_{it}$ | $I_{it}-I_{i(t-1)}-\sum_j X_{ijt}-L_{it}=-d_{it}$；$t=1$ 时 $I_{i0}$ 为常数，右边变为 $I_{i0}-d_{i1}$ |
| (1.3) | 销售损失上界 | $L_{it}\le d_{it}$ | 同 |
| (1.4) | 机器容量 | $\sum_i (s_iY_{ijt}+b_iX_{ijt})\le c_{jt}$ | 同 |
| (1.5) | 兼容性 | $Y_{ijt}\le w_{ij}$ | 同 |
| (1.6) | 延续需先换型 | $Z_{ijt}\le Y_{ijt}$ | $Z_{ijt}-Y_{ijt}\le 0$ |
| (1.7) | 不可连续两期延续 | $Z_{ij(t-1)}+Z_{ijt}\le 1$ | 同 |
| (1.8) | 生产启用 | $X_{ijt}\le U_{ijt}\,(Y_{ijt}+Z_{ij(t-1)})$ | $X_{ijt}-U_{ijt}Y_{ijt}-U_{ijt}Z_{ij(t-1)}\le 0$ |
| (1.9) | 未延续换型的最小批量 | $X_{ijt}\ge m_i(Y_{ijt}-Z_{ijt})$ | $X_{ijt}+m_iZ_{ijt}-m_iY_{ijt}\ge 0$ |
| (1.10) | 延续下的跨期最小批量 | $X_{ijt}+X_{ij(t+1)}\ge m_iZ_{ijt}$，$t\le T-1$ | 同 |
| (1.11) | 每机器每期至多一次延续 | $\sum_i Z_{ijt}\le 1$ | 同 |
| (1.12)–(1.15) | 变量域 | 见上表 | $Z_{ij0}$ 上界 0 |

$U_{ijt}$ 的定义见第 5 节。

## 5. 两个命名模式

### 5.1 `paper_literal` — 公开公式的字面转写

- $U_{ijt}=M_{ijt}=\min\big(\sum_{t'=t}^{T}d_{it'},\ (c_{jt}-s_i)/b_i\big)$，逐 (1.8) 原样使用；
- $Z_{ijT}$ 自由（论文未显式固定）；
- 其余约束同上。

**不悄悄补约束，不修正任何被怀疑的边界。**

### 5.2 `audited_v1` — 明确披露的变体，后续实验的候选基础

与 `paper_literal` 的两处差异：

| 编号 | 差异 | 理由 |
|---|---|---|
| **D1** | 生产启用上界改为 $U_{ijt}=c_{jt}/b_i$（换型时间 $s_i$ 仍由 (1.4) 扣除） | 论文的 $(c_{jt}-s_i)/b_i$ 假设"本期一定重新占用换型时间"。但当生产由**上一期延续**而来（$Z_{ij(t-1)}=1$）时，本期不需要再换型，该上界偏紧 |
| **D2** | 固定 $Z_{ijT}=0$（对所有 $i,j$） | $Z_{ijT}$ 表示"从 $T$ 延续到 $T+1$"，而没有 $T+1$ 期。论文显式固定了 $Z_{ij0}=0$，但未固定末端 |

**其余约束（含 (1.9)）与 `paper_literal` 完全一致**，不做其他改动。

`audited_v1` 是**变体**，不是"忠实复现"。它也不声称修好了论文——只把两处边界疑问变成可检验的显式选择。

### 5.3 边界处理（两种模式共用）

若 $c_{jt}<s_i$，则 $(c_{jt}-s_i)/b_i<0$。右端项不可能为负，故 $U_{ijt}$ 的下界截断为 0，并在 `notes` 中记录受影响的 $(i,j,t)$。实例 D、E 的 `paper_literal` 会触发该记录。

## 7. 求解器与接口

- 求解：`scipy.optimize.milp`（HiGHS），整数变量与连续变量混合，$10^{-6}$ 量级容差；
- 独立枚举路径：固定全部二元变量后用 `scipy.optimize.linprog`（HiGHS）解**纯连续 LP**；
- 固定—释放接口：`solve_milp(bm, fix=...)` 逐变量固定；`solve_milp(bm, free_Y_subset=..., Y_reference=...)` 实现论文 3.1 节的 $Y$ 集合语义（不在 $Y$ 内的短期换型变量硬固定为参考值）；
- 独立验解器：`lsp_checker.check_solution`，**不复用** `build_model` 的约束矩阵，逐条按业务规则重算残差与四类成本。

## 8. 结构性事实（本轮发现，供下一轮参考）

1. **模型恒可行（在参数非负时）**。取 $X_{ijt}=Y_{ijt}=Z_{ijt}=0$，由 (1.2) 递推 $L_{it}$ 即可满足；因 (1.3) 允许 $L_{it}\le d_{it}$ 而销售损失不占容量，缺多少产能都可以用销售损失兜住。本轮曾尝试构造一个"必然不可行"的微型实例用于负向检查，若干候选全部实际可行，故该检查改为"全零见证必须可行"的正向检查（`all_zero_witness_feasible`）。
2. **$I_{i0}$ 是常数项，不是变量**。它只影响 (1.2) 在 $t=1$ 的右端项（$I_{i0}-d_{i1}$），不引入额外列。
3. **`paper_literal` 下，同一产品在同一机器上连续生产不会带来额外产能**。因为 (1.6) 要求 $Z_{ijt}\le Y_{ijt}$，若 $Y_{ijt}=Y_{ij(t+1)}=1$ 则只能取 $Z_{ijt}=0$，于是 $X_{ij(t+1)}\le U_{ij(t+1)}$ 而不享有延续的额外额度；若取 $Z_{ijt}=1$ 则 $Y_{ij(t+1)}$ 仍可为 1，但 $U$ 已按 $c_{jt}-s_i$ 收窄。结论仅限本轮微型实例范围，是否构成建模缺陷见 `stage01_report.md` 第 5 节。
4. **$I_{i0}$ 之外没有其他常数项**。(1.8) 的上界 $U_{ijt}$ 完全由 $c_{jt}$、$s_i$、$b_i$ 和未来需求决定，因此容量为 0 的时段会把该时段的 $U$ 直接压到 0（`paper_literal` 下甚至为负，见 5.3）。在后续构造"故障使 $c_{jt}=0$"的重优化实例时，这一点会同时影响容量约束和启用上界，需要显式记录。
