# Stage 12：受限问题的质量保留诊断

## 两个问题

> **AB 相对随机固定的优势，有多少能由受限问题最优值的差异确认？AB 自己又可能因固定 C 损失多少质量？**

**回答一（有明确证据）**：**有 5 个状态、覆盖 5 个名义实例，可以确认 AB 的可达最优质量严格优于 MR-Z-1**（区间下端 > 0）；**反向（MR-Z-1 更好）确认 0 个**。若把三个随机集都计入，**证书共 12 个、覆盖 6 个状态 / 5 个名义实例**，其中最强的一例给出 `J*_AB ≤ 6618.56 < 7630.08 ≤ J*_MR-Z-3`（相对差 **+10.32%**）。

**回答二（仍未解决）**：**AB 因固定 C 相对 ABC 的质量损失，16/16 个状态的区间都跨越 2% 工程尺度**——下界基本为 0（无法确认存在损失），上界 2.8%–9.2%（无法确认损失 <2%）。**本轮预算没有把这一项收窄到可判定。**

**这没有改变 Stage 11 的部署判据，也不证明远期位置普遍优越。** 但它说明：**至少部分差距确实包含固定集合造成的质量损失，不能全部归于搜索规模。** 因此按预案第一条，**下一步应研究哪些固定条件排除了好解**，优先检查随机固定的短期 Z。

**方向决定**：按你给的预案分支，出现更多 `L_MR > U_AB` 证书 → **不把全部差距归因于计算规模**；同时 AB 与 MR 的最优值差**未**被限制在 ±2% 内（10/16 仍未确定），所以**现在还不该把重点转向搜索难度与预处理结构**。

## 4. 结论与下一步

**按预案逐条对照**

| 预案 | 是否成立 | 证据 |
|---|---|---|
| 出现更多 `L_MR > U_AB` 证书 → **研究哪些固定条件排除了好解，优先检查随机固定的短期 Z；不把全部差距归因于计算规模** | **成立** | 12 个证书 / 5 个状态确认 AB 更好；反向 0 |
| AB 与 MR 的最优值差已被限制在 ±2% 内，而限时表现仍不同 → 转向搜索难度与预处理结构 | **不成立** | 仅 **1/16** 状态限制在 ±2% 内；**10/16 仍未确定** |
| AB 相对 ABC 的损失上界 < 2% → 支持"限制搜索范围同时保留足够好解" | **不成立** | 16/16 状态的损失上界都 > 2%（2.8%–9.2%） |
| 损失下界 > 2% → 确认 AB 有实用尺度的质量代价 | **不成立** | 下界基本为 0，**没有**确认存在 ≥2% 的损失 |
| 60 秒后区间仍宽 → 记为未解决，不自动加时，也不据此否定方向 | **适用** | 区间2 全部未收窄；区间1 有 10/16 未确定 |

**结论**：

1. **可达质量差异确实存在**，且方向一致地支持 AB：**5 个状态确认** AB 的可达最优优于 MR-Z-1，**0 个反向**。**部分差距不是计算规模问题**，而是固定集合本身排除了更优解。
2. **但不能说"远期位置普遍优越"**：确认只覆盖 5/16 状态；另有 1 个状态两者差异被限制在 ±2% 内；10 个仍未确定。
3. **AB 相对 ABC 的质量代价仍未解决**：损失下界 ≈0、上界 2.8%–9.2%，16/16 跨越 2%。**既不能说代价可忽略，也不能说代价≥2%。**
4. **Stage 11 的部署判据不变**（+1.70%，判"不确定"）；**20 秒部署预算不变**；**GRL 仍不启动**。

**下一步（本轮不做，按预案）**：**研究哪些固定条件排除了好解，优先检查随机固定的短期 Z。** 具体地，证书状态里 MR 的固定集**固定了约 279 个 B 槽位**——需检查是这些被固定的短期 Z 阻断了跨窗口延续，还是随机固定集在 C 中保留的那 ~279 个自由槽位造成了别的后果。

## 5. 边界

- **这是离线质量诊断，不是部署比较**：60 秒预算、单种子、跨配置方案池起点都**不构成**三种方法的部署成绩；**20 秒部署预算未变**。
- **`U` 使用 Stage 11 两个种子的较优者，仅作离线质量证书**，不是可部署结果，也不把两种子的预算合并成一次运行。
- **区间来自求解上下界，不是统计置信区间**；也不能解释为"最优值差异的概率范围"。
- **所有界来自同一状态、同一配置定义**；不同配置的界不混用。
- **`L` 可能被高估的余地很小但非零**：HiGHS 报告的下界在时限下是有效下界；LP 松弛界独立求解并**全部证最优**（80/80）。
- **区间2 只相对于 ABC**（仍固定短期 Y），**不能**外推到 FULL。
- 0/48 证最优，故所有 `U` 都只是上界，**`J*` 的真实值可能更低**——这只会让区间更宽，不会让证书失效。
- 未生成新实例、未改名义计划/修复器/κ/模型/求解器配置、未扫参、未自动延时、未训练模型。
