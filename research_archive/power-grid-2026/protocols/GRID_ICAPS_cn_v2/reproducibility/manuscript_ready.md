# 基于变电站补全的电网渐进拓扑搜索

## 摘要

在线电网控制通过预测仿真比较拓扑动作，候选评估的计算开销直接影响控制效率。全局排序将同一变电站的不同配置分散排列，提前停止可能遗漏已发现变电站内的优质配置，增加后续运行成本。本文提出渐进拓扑搜索框架 FRAME，将分批评估与变电站补全结合：根据已获得的反馈扩展候选前缀，在扩展停止后集中比较当前最佳候选所在变电站的剩余配置，以局部补查改善提前停止的质量与计算权衡。在 Grid2Op 的四个开发日期上，FRAME 相对完整搜索减少了 69.37% 的候选查询和 13.11% 的控制时间，补全将最坏完整周成本增幅从 4.810% 降至 0.372%；在另行冻结的三个确认日期上，FRAME 保持与完整搜索相同的存活结果，控制时间减少 6.09%，两个发生搜索的日期平均减少查询 83.54%，完整周成本增幅最高为 0.014%。实验表明，利用动作的结构归属分配额外评估，可以在保留大部分搜索节省的同时改善控制质量。

关键词：电网拓扑控制；在线搜索；计算分配；变电站补全

## 1 引言

电网拓扑控制通过调整线路、发电机和负荷与母线的连接关系缓解拥塞。在线控制器需要随负荷与发电变化，将拓扑调整与再调度、弃电、储能和恢复操作协调起来。预测仿真使控制器能够在执行前检查候选动作的后果，也引入了逐候选评估的计算开销。Grid2Op 为这一连续决策过程提供了公开实验环境 [1]。如何以较少的评估获得高质量动作，是提高在线控制效率的关键。

已有方法通过混合控制与学习排序提高动作选择效率。LJN 智能体结合连续优化和离散拓扑搜索 [2]；SoftGNN 及相关图学习方法利用电网结构为动作排序，再通过仿真验证候选 [3,4]。这些方法为有希望的动作赋予较高优先级，使控制器能够在搜索前段获得可用方案。随着候选池扩大，控制器还需要决定何时停止评估，以及停止前应进一步比较哪些动作。

全局排序与拓扑动作的结构分组之间存在一个具体的不一致：同一变电站的不同配置可能相距很远。搜索已经发现某个有效变电站后，即使连续几个候选未带来奖励提升，该站仍可能保留尚未查询的有效配置。此时直接结束搜索，可能错过位于序列后部的更好配置；继续遍历整个候选池，则会增加大量其他变电站的评估。这个问题为结构化地分配剩余计算提供了机会。

本文提出 FRAME，将渐进前缀搜索与当前最佳候选的变电站补全结合起来。前缀搜索负责快速找到可接纳方案，并依据奖励改进和预测负载率决定扩展长度；变电站补全负责在扩展停止后，集中评估已发现结构单元内的剩余配置。两部分形成由全局发现到局部比较的搜索流程。该流程通过统一接口接入混合控制器，候选排序器可以按应用需要替换。

本文的主要贡献包括三点。第一，提出结合渐进停止和变电站补全的拓扑搜索框架，将有限评估集中到当前有价值的配置组。第二，给出保留物理等价动作别名的补全集合构造，使规范化后的动作仍能准确归入原始变电站，并保证补全保留此前最佳的已观测选择结果。第三，通过闭环对照、模块消融和逐步案例分析，展示框架的质量与计算收益：开发实验减少约七成查询，同时将提前停止造成的最大完整周成本增幅压至 0.372%；冻结日期进一步保留了相对完整搜索的查询与控制时间节省。

## 2 方法

### 2.1 框架概述

FRAME 的核心思想是先利用排序定位有价值的动作，再利用变电站结构补足局部比较。图 1 展示了整体流程：控制器生成当前可用的拓扑候选，将物理等价动作合并为代表；搜索层先评估排序前缀，按反馈逐批扩展；扩展达到停止条件时，对当前最佳候选所在变电站进行一次补全，最后将选中的拓扑提案交回基础控制器。基础控制器继续负责连续控制与恢复。

这两个搜索阶段承担互补任务。渐进评估控制全局搜索量，避免每次遍历整个动作池；结构补全利用已发现候选的归属，检查全局排序中分散的同站配置。排序器提供优先顺序，搜索层决定实际查询集合。

### 2.2 问题定义

在决策时刻 t，控制器获得当前观测 x 和基础连续动作 b。原始拓扑动作库记为 I，每个动作具有标识 i 与变电站标签 s(i)。系统依据合法性和冷却时间筛选动作，处理断线端点，并将拓扑干预与 b 组合。对当前状态下产生相同物理动作向量的候选，系统保留一个规范化代表。记 rep(i) 为原始动作到代表的映射，A 为排序后的代表集合，同时保存全部原始别名及其变电站标签。

查询 Q(x,b,a) 对候选 a 进行预测仿真，返回奖励 r(a)、最大线路负载率 ρ(a) 及终止、异常和合法性标志。FRAME 根据当前观测、固定动作元数据和已经执行的查询反馈选择后续候选。为沿用基础控制器的动作筛选要求，我们将满足以下负载率条件且通过合法性检查的候选称为可接纳候选：

\[
0 < \rho(a) < \min\{\rho(x),\theta\}.
\]

其中，ρ(x) 为当前最大线路负载率，θ 为基础控制器传入的阈值；合法性检查要求预测未终止，且没有异常、非法或歧义动作。在可接纳候选中，我们使用以下选择键比较动作：

\[
f(a)=\bigl(\operatorname{fp32}(r(a)),-i(a)\bigr).
\]

该键优先选择预测奖励较高的动作，并在奖励相同时选择标识较小者。fp32 表示单精度浮点转换，i(a) 为代表保留的动作标识，二者与基础实现保持一致。搜索层输出最佳可接纳拓扑提案；没有可接纳候选时，由基础控制器执行原有回退流程。

### 2.3 渐进候选评估

渐进评估先查询前 min(128,|A|) 个代表，并建立当前最佳候选。若候选池已经耗尽，或最佳候选的预测负载率低于 0.9，则直接返回。这个前缀为控制器提供一次集中比较的机会，使较容易处理的状态能够尽早完成决策。

其余状态以每批最多 64 个候选继续扩展。每批结束后更新最佳选择键：获得改进时，将连续无改进计数清零；否则计数加一。当最佳候选的预测负载率低于 0.9，或累计至少查询 256 次且连续两批没有改进时，结束全局扩展。若始终没有可接纳候选，则继续搜索直到候选池耗尽。

负载率条件识别已获得较好预测状态的情形，连续无改进条件则控制奖励平台上的额外计算。停止后留下的候选中，同一变电站的未查配置交由下一阶段集中处理。

### 2.4 变电站结构补全

结构补全针对全局排序中分散的同站配置。设扩展结束时已查询代表集合为 C，最佳可接纳候选为 a_C，选定变电站为 s_C=s(i(a_C))。需要补查的代表集合定义为

\[
L=\{\operatorname{rep}(i)\in A\setminus C:s(i)=s_C\}.
\]

这个定义通过原始别名确定归属：只要代表的任一原始别名属于 s_C，该代表就进入补全集合。这样，物理等价合并既减少重复评估，又保留完整的结构关系。FRAME 查询 L 中每个代表，并从 C∪L 中返回选择键最大的可接纳候选。

补全使用扩展结束时选定的变电站，执行一次。它在经过扩展、已有最佳候选且仍有未查询项时触发；初始前缀直接返回的分支保持低开销。算法 1 给出完整流程。

```text
算法 1 渐进搜索与变电站补全
输入：有序代表池 A；查询接口 Q；别名映射与变电站标签 s
C ← 查询前 min(128, |A|) 个代表
a ← C 中最佳可接纳候选
若 C 已耗尽 A，或 a 存在且 ρ(a) < 0.9，则返回 a
stale ← 0
当仍有未查询候选时：
    查询下一批至多 64 个代表；更新 C 和 a
    选择键改进时 stale 归零，否则 stale 加一
    若 a 存在，且 [ρ(a) < 0.9 或 (查询数 ≥ 256 且 stale ≥ 2)]：
        结束扩展循环
若 a 存在且 C 未耗尽 A：
    s_C ← a 的原始变电站
    L ← 所有具有 s_C 别名且尚未查询的代表
    查询 L 一次；按相同可接纳规则与选择键更新 a
返回 a；若没有可接纳候选，则交由基础控制器回退
```

### 2.5 补全性质与查询开销

补全保留已获得的最佳反馈，同时增加局部候选的比较。设补全前后最佳候选分别为 a_C 与 a_after，则 f(a_after)≥f(a_C)。这是因为 a_C 仍在 C∪L 中，而更新只接受更大的选择键。补全的额外查询数为 |L|；查询登记保证每个规范化代表最多评估一次，整个搜索的查询数不超过 |A|。

这一性质使局部补查具有明确的收益方向和计算账目：已观测的最佳选择被保留，新增评估集中在选定变电站。其对多步运行的影响通过下一节的闭环实验检验。

## 3 实验

### 3.1 实验设置

实验使用公开 l2rpn_idf_2023 环境、LightSim2Grid 和基于 LJN 的混合控制器 [1,2]。原始拓扑动作库包含 909 个动作，当前候选池由合法性筛选与等价合并得到。四种方法共享作者频次排序、连续控制、恢复策略、预测接口以及 DC/safe-QP 编译缓存，比较集中于搜索停止和结构补全。

| 策略 | 搜索行为 |
|---|---|
| FULL | 评估全部合法规范化代表，选择键最大的可接纳项。 |
| FIRST_SAFE_BEST | 返回首个 ρ<0.9 的可接纳预测；若未找到而耗尽候选池，保留最佳可接纳项。 |
| NO_LOCAL | 沿用 FRAME 的前缀、批次和停止规则，只关闭结构补全。 |
| FRAME | 渐进评估后执行有条件的变电站补全。 |

FULL 提供完整候选搜索参照；FIRST_SAFE_BEST 采用首个达到负载率阈值即返回的原则，并在遍历后保留最佳可接纳项；NO_LOCAL 用于检验结构补全的作用。共同排序采用频次先验，所有主实验使用相同顺序。

实验分为开发和确认两组。开发组包含 2035-03-05_0、2035-06-25_8、2035-09-03_4、2035-10-01_5 四个日期，共 32 条运行。确认组包含此前未用于本地开发的三个日期变体：2035-04-09_3、2035-05-14_14、2035-11-19_0，共 24 条运行。确认日期由固定元数据规则选出；运行前冻结策略、阈值和执行顺序。每组均为四种方法、每日期两次平衡串行重复。

实验主机为 AMD Ryzen 9 8940HX，系统为 Windows 11。软件包括 Python 3.12.14、Grid2Op 1.12.5、LightSim2Grid 1.1.0、CVXPY 1.9.3、Clarabel 0.11.1 和 OSQP 1.1.3。回放采用单个串行 CPU 工作进程，数值库设为单线程。

### 3.2 评价指标

我们同时衡量候选查询数、实际控制时间、完整周运行成本和存活步数。控制时间包括搜索准备、排序、预测仿真和连续控制，环境步进、初始化与结果保存单列。记 T_m,d,j 为方法 m 在日期 d、第 j 次重复的控制时间，先对同日期重复取平均：

\[
\bar T_{m,d}=\tfrac12(T_{m,d,0}+T_{m,d,1}),
\]

再计算各日期相对 FULL 的节省比例并等权平均：

\[
S_T(m)=\tfrac1{|D_T|}\sum_{d\in D_T}\left(1-\frac{\bar T_{m,d}}{\bar T_{\mathrm{FULL},d}}\right).
\]

D_T 包含运行长度相同的比较。查询节省采用相同聚合方式，分母为 FULL 的查询数，零查询日期单列。完整周成本变化为 (J_m,d−J_FULL,d)/J_FULL,d，正值表示成本增加，只在双方都完成整周时计算。成本按 L2RPNSandBoxScore 计量，包含损失能量、再调度绝对能量、弃电能量变化和储能吞吐能量的加权和。

质量判据在运行前固定：相对 FULL 没有更早失败，且可比较完整周成本增幅不超过 0.5%。确认实验另外要求至少两个完整可比较日期、平均控制时间减少至少 5%，且至少两个日期时间减少。所有结果按日期汇总。

### 3.4 结构补全的作用

移除补全最明显的影响出现在 3 月开发日期。NO_LOCAL 的完整周成本比 FULL 高 4.810%，FRAME 将该差距缩小至 0.372%。在第 1733 步，NO_LOCAL 查询 256 个候选后选择动作 26；FRAME 随后对选中变电站增加 198 次评估，选中动作 309，与 FULL 评估 909 个动作后的选择一致。FRAME 在该步使用 454 次查询，找回了排序前缀中遗漏的有效配置。

这个案例揭示了结构补全如何发挥作用：全局前缀已经定位到有效变电站，局部补查进一步完成配置比较。保存状态复核中的 90 次 FRAME 调用有 12 次因补全改变动作选择。闭环消融与逐步记录共同支持了围绕已发现结构单元继续评估的设计动机。

补全的收益随状态变化。确认组 4 月，FRAME 相对 NO_LOCAL 的成本改善为 FULL 成本的 0.00782%；11 月没有触发补全，两者物理轨迹与成本相同。计算上，FRAME 相对 FULL 的时间降幅比 NO_LOCAL 在开发组少 1.15 个百分点、确认组少 3.30 个百分点，体现了局部比较所支付的额外开销。

### 3.5 停止策略与时间表现

FIRST_SAFE_BEST 用更积极的停止换取较少查询。它在开发组通过 2/4 个日期的质量判据，在确认组通过 3/3，说明首个达标动作在部分场景中已经足够有效。FRAME 在开发组通过 4/4，同时在确认组保持 3/3，呈现了更充分比较所带来的质量表现。

确认组 FIRST_SAFE_BEST 的全日期时间均值受到零搜索日期的计时波动影响。为理解这一现象，对两个实际搜索日期另作描述性统计：FIRST_SAFE_BEST 的控制时间减少 11.92%，FRAME 减少 8.25%。因此，实际应用可以依据质量要求和计算预算，在较早返回与结构补查之间作选择。

相同方法的重复物理轨迹一致，墙钟时间仍有波动。例如，4 月 FRAME 的两次控制时间为 76.28 和 44.73 秒；5 月 FIRST_SAFE_BEST 为 13.43 和 6.84 秒。主表按预定方式保留两次计时。查询量反映搜索工作量，控制时间反映当前实现和机器上的整体开销，两项指标共同刻画效率。

## 4 结论

本文提出基于变电站补全的渐进拓扑搜索框架，将全局前缀评估与局部配置比较结合起来。框架利用查询反馈控制扩展长度，并在扩展停止后补查当前最佳候选所在变电站，以改善搜索效率与控制质量的权衡。开发实验相对完整搜索减少 69.37% 的查询和 13.11% 的控制时间，同时将去补全策略的最大完整周成本增幅从 4.810% 压至 0.372%；冻结日期实验继续获得查询和时间节省。结果为在线电网控制提供了一个可接入既有混合控制器的搜索方案，也展示了动作结构信息在分配评估计算中的作用。

## 5 相关工作

### 5.1 电网混合控制与学习排序

混合控制将连续优化与离散拓扑决策结合，公开 LJN 智能体为本文提供基础控制器与动作库 [2]。学习排序进一步利用电网状态和结构安排候选优先级。SoftGNN 通过软标签学习多个有效拓扑动作的偏好，并逐候选执行预测验证 [3]；de Jong 等研究了图神经网络在拓扑变化下的泛化及其与验证搜索的结合 [4]。FRAME 在排序之后组织实际评估，将渐进扩展与同站补全接入这一控制流程，排序模型可作为其中的辅助组件。

### 5.2 搜索过程的计算分配

规划中的元推理研究如何在推演收益与计算费用之间作决策。Bhatia 等通过深度强化学习调整随时规划的超参数和计算过程 [5]，有界最优元推理将推演成本纳入策略评价 [6]。本文采用结构启发式分配单步仿真：全局阶段利用已观测改进决定扩展，局部阶段利用最佳候选的变电站归属决定补查对象。这使停止判断与后续评估集合形成明确的联系。

### 5.3 结构化邻域比较

围绕当前解检查相关替代方案是邻域搜索的基本思路。FRAME 将这一思路落实为当前动作空间中的变电站补全集合。原始动作别名参与集合构造，使物理等价合并后的候选仍保留结构归属；补全在扩展停止后执行，并复用已有反馈。这种组织方式将额外查询集中到选定配置组，实验通过 NO_LOCAL 消融和逐步动作记录检验其作用。

## 6 局限

当前闭环实验覆盖一个电网、四个开发日期和三个确认日期，后续需要在更多日期与电网上检验参数适应性。确认日期排除于本地训练和调参；外部频次先验的原始教师日期范围仍待核实。局部补全的较大成本收益集中在一个开发日期，FIRST_SAFE_BEST 在确认组同样具有竞争力。

墙钟结果受到运行波动影响，当前报告给出两次重复的实测均值；其中零搜索日期的时间差来自控制循环其他部分。更稳定的计时重复有助于进一步量化整体加速幅度。仿真中的运行成本按基准计量，实际部署仍需结合运行规则和独立安全评估。

补全性质针对单次查询集合中的最佳选择键。长期成本和存活由闭环运行检验，最坏查询量可达到整个候选池。现有复核基于保存状态、反馈和成本向量，独立交流潮流重求解与跨平台复现可作为进一步验证。
