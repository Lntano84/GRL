## 1. 冻结配置与两处必须说明的执行偏差

| 项 | 值 |
|---|---|
| 工作负载 | JOB：113 查询 × 49 hint |
| 等价类 | 来自 EXPLAIN 计划的 `hint_list`；**113/113 行标签全部匹配**，0 冲突，1,393/1,393 个多 hint 类数值一致 |
| D | Σ W[q,0] = **181.0846** |
| 预算 | 0.25D / 0.5D / D = 45.27, 90.54, 181.08 |
| 种子 | [0, 1, 2]；四臂 × 三预算 × 三种子 = **36 次回放** |
| 预测器 | `censored_als(rank=5, lambda=0.2, iters=50)`，未扫参 |
| 截止值 | 新候选 `min(b_q, 15.0 * x_hat)`；重试 `min(b_q, 2.0 * L)` |

### 1.1 执行偏差（必须明说）

**第一，初始测量成本单列，不占用探索预算。**
第 0 列基线本身花费 **恰好 D = 181.0846**。若把它记入预算，则 `B = 0.25D` 会被初始化一次耗尽，
四臂退化成同一条轨迹（我第一版实现正是如此，四臂 P 完全相同——这是你指出的「接口还没接好」的直接后果）。
因此本轮把 `init_cost` 作为**所有方法相同的独立行项**单独计费，预算 B 只用于其上的探索。
每次回放的合计模拟耗时 = init_cost(181.0846) + B。

**第二，预算的货币是模拟执行秒数，策略计算耗时（wall-clock）单列。**
把 wall-clock 秒加进模拟秒会混合单位，因此没有相加，而是并列报告（§5）。

**其它均为冻结配置：** 初始化只用第 0 列及其等价类（不使用来源未解释的 `init_mask`）；
同一等价类内一次观测传播给整类、只收一次执行成本；所有方法排除已完成候选与 `L ≥ b_q` 的候选；
非正/非有限预测不得产生零成本动作，一律进入统一随机回退并计数；
派发前检查剩余预算，末次截止值不超过剩余预算，**不使用真实耗时预判「这次来得及完成」**。

## 4. 为什么重试没有触发（本轮最关键的事实）

| 量（B = D，三种子合计） | MF-RETRY |
|---|---:|
| 探索动作 | 239 |
| **其中重试动作** | **1** |
| 发生超时 | 144 |
| 随机回退次数 | 3 |

重试并非不可行：三种子合计有 **185 个（类别, 决策）对**是「重试可行」的。
但按该臂**自己的打分**，这些类别排得极低：

| 种子 | 决策数 | 含重试可行类的决策 | 由重试类居首的决策 |
|---:|---:|---:|---:|
| 0 | 44 | 36 | 0 |
| 1 | 51 | 48 | 0 |
| 2 | 63 | 27 | 1 |

典型情形（seed 1，决策 3）：1,788 个候选中有 1 个重试可行类，它排在第 **63** 位。

### 4.1 根因

超时产生的下界不可能超过该次的截止值，而截止值至多为 `b_q`。因此：

> 一个超时类要保持 `L < b_q`（即重试可行），只有当它的截止值**严格小于** `b_q`。

而冻结的截止规则是 `cap_new = min(b_q, 15 x̂)`。在 JOB 上，第 0 列基线把多数 `b_q` 压得较小，
于是 `15 x̂ ≥ b_q` 经常成立、`cap_new` 就等于 `b_q`；这类超时一发生就落在 `L ≥ b_q`，
按既定规则被**合法剪枝**，永远不再成为候选。

只有 2 次留下重试可行的下界。

**换句话说：在这份冻结配置下，「提前截止」这一半在起作用，而「重试」这一半被 α = 15 的截止规则
本身挤掉了。** 这是配置的后果，不是方法的评价。

## 6. 判读

| 预先固定的档位 | 是否命中 |
|---|---|
| 三种子均更好 + 平均 ≥2% + 优于两个廉价对照 → 进入第二工作负载确认 | **否** |
| MF-BEST 三种子均不差，或廉价对照稳定更好 → 不扩展该方案 | **否**：廉价对照并未更好（三个种子都更差）|
| **方向混合或差距小 → 记为不确定，不改倍率、不追加种子** | **本轮落在这里** |
| 只有隐藏真值诊断发现改善空间 → 不算通过 | 未使用该档 |

### 6.1 本轮真正测到了什么

**必须和门槛结果分开写：**

1. 在 JOB、这份初始化与这三档预算下，**全局经验中位数基线无法容纳**「提前截止＋重试」组合的净收益
   —— 但**主要原因是重试分支被截止规则挤掉**，不是因为发现了重试无价值。
2. 「提前截止」那一半确实在工作：MF-BEST 在三个种子都优于 GREEDY-BEST，
   说明按预测改善/执行成本排序比「优先最大 b_q」更省预算。
3. 这**不是**对方向的否定：我**没有**得到「重试无用」的证据，因为重试只发生了 1 次。

### 6.2 我明确不做的

按你的固定判读，**不改倍率、不追加种子**。因此我**不**去调 α = 15 来「让重试发生」——
那正是你警告过的「不断修改场景」。若要让重试可被检验，应当**重新预注册**一个不同的截止规则，
并把「重试发生率」当作**设计参数**在跑之前固定。

## 7. 限制

1. **单个工作负载（JOB）**，三种子**不构成跨工作负载泛化证据**，也不构成统计显著性。
2. **2% 是筛查门槛**，不是显著性或论文标准。
3. **重试发生率 0.4%**，所以主比较对「重试」这一半几乎没有检验力（§4）。
4. **初始化作为独立行项**，总模拟耗时 = init_cost + B（§1.1）。
5. **预算货币是模拟秒**，策略墙钟单列，未相加。
6. **删失低秩预测器是拟合过的轻量模型**；本轮报告应表述为「拟合了固定的删失低秩预测器」，
   **不得**写成「没有训练任何模型」。
7. 所有方法共用一个预测器与一个排序规则，因此本轮不分解「重试的单独因果贡献」。
